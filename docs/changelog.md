# 更新履歴

アプリの「モード選択 → 情報 → 更新履歴」に表示する。新しい版を上に足す。書式は「## 版（日付）」の見出しと「- 」の箇条書きだけ（`src/core/changelog.ts` が読む）。以後のタスクで、遊ぶ人に見える変更をここに追記する（CLAUDE.md の「更新履歴」）。版はフェーズの番号（0.N.0 = フェーズ N）で、0.1〜0.6 は 8-1 で `docs/plan.md` から要約した。

## 1.0.3（2026-11-04）

- タッチの狙いの補助を強くした（敵が機首の近くにいると、より広い範囲から、より強く機首を合わせる）。設定 → 操作の「狙いの補助（タッチ）」で弱（今までの強さ）・標準・強を選べる
- タッチの自動射撃: 選んだ敵が当たる所に入って射程内のときだけ、機銃を自動で撃つ（初期値 ON。設定 → 操作の「自動射撃（タッチ）」で OFF にできる）。GUN ボタンもそのまま使える
- タッチの「方向へ倒す」操作で宙返り: 速さがあるときに上へ倒し続けると、そのまま縦に 1 回転する（頂点で離すと、水平に戻って反対向きに飛ぶ）。速さが足りないときは HUD に NEED SPEED
- PvP（個人戦・チーム戦）では、狙いの補助・自動射撃はロビーの補正で部屋ごとに ON / OFF（初期値 OFF = 今までどおり）。チュートリアルの説明に自動射撃と宙返りを足した

## 1.0.2（2026-11-03）

- タッチの操作を新しくした: スティックを行きたい方向へ倒すと、そちらへ曲がる（右へ倒すと右へ、上へ倒すと上へ。傾けて引くのはゲームがする）。地面や海に近いときは引き起こしを助ける。元の操作（ピッチ・ロール）は設定 → 操作の「操縦（タッチ）」で選べる
- スティックの感度のカーブ（1.0 / 1.5 / 2.0。初期値 1.5 で、中央付近が細かくなる）と、スティックの位置（親指の場所 / 左下に固定）を設定で選べるように
- チュートリアルの操作の説明を新しい操作に合わせた。今までの人には、最初の飛行で一度だけお知らせを出す

## 1.0.1（2026-11-03）

- iPhone のホーム画面から横向きで起動したときに、画面の下に黒い余白が残ることがあったのを直した（起動の直後に画面の向きが遅れて決まるとき、画面を整える処理が動いていなかった）
- 起動時に画面を整える間の黒い画面に、また中央にロゴが出るように（ロゴが読めないときは「SkyRaid」の文字）
- 英語の画面のハンガーの塗装で、デカールの名前が「…」で切れていたのを短い名前に（Triple Diamond → Diamonds、Compass Star → Compass）

## 1.0.0（2026-11-02）

- 公開版。キャンペーン 5 ミッション・リングレース 4 コース・防衛戦 10 波・怪獣レイド・PvP（2〜4 人）・協力（2〜4 人）を、パソコンとスマホ（タッチ・キーボード・ゲームパッド）で。日本語と英語に対応。ホーム画面に追加でき、PvP・協力以外はオフラインでも遊べる
- オンライン連携（クラウドセーブ・メンバー内のランキング）はメンバー限定の任意の機能。使わなくても全モードを遊べる
- リプレイ: 前の版の記録（.skyreplay を含む）を再生するときは「前の版（vX）の記録なので、結果が変わることがあります」とお知らせ（再生はそのまま続く）。これからの記録には作ったときの版が入る
- 起動時に画面を整える間の黒い画面の中央にタイトルのロゴを出すように（固まったように見えないように）。英語の画面のロビーの「補正」を Handicaps から Modifiers に（強化の無効・初心者保護の両方を含むため）

## 0.9.0（2026-11-02）

- 名前をパイロット名の 1 つに（変更は設定 → データの「パイロット名を変更」だけ。オンライン連携の欄は説明の中に今の名前を表示。ランキング・メンバー管理の名前もパイロット名になり、変えるとすぐ反映）。メンバー管理を 1 人 1 行（名前・申請日・状態・操作）の表に
- iPhone の横画面で、ゲームの画面が端まで描かれるように（起動時・向きを変えたときに横や下に黒い余白が出ていた。ホーム画面から横向きのまま起動して下に黒い帯が出るときも、ボタンや表示が帯に隠れないように。直すときの画面のチラつきは黒い画面で隠す）。メニューのボタンを押すときに指が少しずれても選ばれるように。ハンガーの塗装で画面が横にずれていたのを直した
- 排気（陽炎）の先に出ていた細い黒い輪を消した。記録カードの見出しで、日本語の文が一部だけ違うフォントで描かれていたのと、記録カードの画面などで一部の文字が明朝体で出ていたのを直した
- M1 訓練: リングの後の敵機を機銃でも倒しやすく（HP 120 → 72）、ミサイルを撃ち尽くすと 8 秒で補充（お知らせを表示。キャンペーンの全ミッション共通）。M2 初陣: 敵機を 3 機とも easy にし（3 機目は normal だった）、HP 120 → 72・出てくる間隔 20 → 30 秒
- レイド: 高難度を難しく（受けるダメージ ÷2.3・攻撃の間隔 ×0.85・威力 ×1.15）、通常は少しだけ（受けるダメージ ÷1.35・脚を壊したダウン中のダメージ 2 倍をなくした）。協力は人数が増えても 1 人より時間がかからないように人数ごとのダメージの倍率を上げ（2〜4 人 ×1.75 / ×1.25 / ×1 → ×2.3 / ×1.8 / ×1.5）、ブリーフィングのダウンの説明を難易度ごとに

## 0.8.0（2026-11-02）

- 設定 → データに「パイロット名を変更」（8 文字まで）。オンライン連携中はランキングの表示名も変わる（通信に失敗したときは次に連携したときに変更）。ポーズの設定の並びを 画質・HUD・音量・操作補助 に（HUD を画質の右に）
- 公開前の点検（全モードの起動・初回起動・セーブの移行・PWA・オフライン）と、使われていないコードの整理。起動時の読み込みを軽く（フォトモード・リプレイの一覧・情報画面などは使うときに読み、時間がかかるときと失敗したときはお知らせ）。協力レイド・協力防衛戦のロビーの見出しをモードの名前に
- 古いブラウザ・WebGL が使えない環境では動作環境の案内を表示。画面の描画が途切れたとき（iPhone でアプリを裏に回したときなど）は飛行中ならポーズにして復帰、保存できない環境（プライベートブラウズなど）ではそのお知らせ、スマホの縦画面ではメニューでも「画面を横にしてください」。情報画面の「版」に動作環境、「データの扱い」の文面を見直し（P2P では相手に IP アドレスが見えること）
- 英語に対応（初回はブラウザの言語。設定 → 表示 → 言語で切り替え）。数値・日付の表示を言語に合わせた（日本語の日付は「2026/11/02」の形に）
- 結果画面（キャンペーン・ソロのレイド・リングレース・ソロの防衛戦）に「記録カード」: 結果を 1 枚の画像（1200×630）にして共有・保存（パイロット名を載せるかは選べる）。リンクのプレビュー用の画像（OGP）。リプレイの一覧の結果を今の言語で表示（これから記録するもの）、英語の画面の更新履歴に断りの 1 行、「Next Foe」を「Next Enemy」に
