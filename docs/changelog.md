# 更新履歴

アプリの「モード選択 → 情報 → 更新履歴」に表示する。新しい版を上に足す。書式は「## 版（日付）」の見出しと「- 」の箇条書きだけ（`src/core/changelog.ts` が読む）。以後のタスクで、遊ぶ人に見える変更をここに追記する。

## 0.7.0（2026-11-01）

- モード選択を「遊ぶ」と「管理」の 2 段に。カードに人数と進捗（キャンペーンのクリア数・レースのランク・防衛戦の最高波・レイドの最速）
- 設定を独立した画面に（タイトルの歯車・モード選択の「設定」・ポーズの「すべての設定」から）。ポーズには画質・音量・操作補助・HUD だけを残した
- 「情報」画面: 版・更新履歴・使用ライブラリのライセンス・データの扱い
- お知らせ（更新・ホーム画面に追加など）のボタンが折り返さないように
- タイトルの右上に設定の歯車と版

## 0.6 まで（2026-10）

- スマホの UI 総点検（ボタンの折り返し・タッチのホバー・選択項目のセグメント化・HUD の配置）
- リプレイ（記録・再生・保存・書き出し）、フォトモード
- オンライン連携（メール認証・クラウドセーブ・メンバー内ランキング）
- スキンとデカール、天候と時間帯、防衛戦、リングレース
- 怪獣レイド（ソロ・協力 2〜4 人）と港湾都市
- PvP（2〜4 人・チーム戦）
- 機体 4 種と強化、キャンペーン 5 ミッション、チュートリアル
