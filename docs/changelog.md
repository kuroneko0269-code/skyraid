# 更新履歴

アプリの「モード選択 → 情報 → 更新履歴」に表示する。新しい版を上に足す。書式は「## 版（日付）」の見出しと「- 」の箇条書きだけ（`src/core/changelog.ts` が読む）。以後のタスクで、遊ぶ人に見える変更をここに追記する（CLAUDE.md の「更新履歴」）。版はフェーズの番号（0.N.0 = フェーズ N）で、0.1〜0.6 は 8-1 で `docs/plan.md` から要約した。

## 0.8.0（2026-11-02）

- 設定 → データに「パイロット名を変更」（8 文字まで）。オンライン連携中はランキングの表示名も変わる（通信に失敗したときは次に連携したときに変更）
- ポーズの設定の並びを 画質・HUD・音量・操作補助 に（HUD を画質の右に）
- 公開前の点検（全モードの起動・初回起動・セーブの移行・PWA・オフライン）と、使われていないコードの整理
- 情報画面の「データの扱い」の文面を見直し（P2P では相手に IP アドレスが見えること）
- レイド・防衛戦の「協力」から入るロビーの見出しを「協力レイド」「協力防衛戦」に
- 起動時の読み込みを軽く（フォトモード・リプレイの一覧・情報画面などは使うときに読む）。読み込みに時間がかかるときと失敗したときはお知らせを出す

- メニューの再設計（「遊ぶ」と「管理」の 2 段・独立した設定画面・情報画面・タイトルの歯車と版）

## 0.6.0（2026-10-31）

- 怪獣レイド: 怪獣ヴォルガス（部位 HP・4 種の攻撃と予兆・フェーズとブレイク）、ソロと協力 2〜4 人

## 0.5.0（2026-10-31）

- PvP ドッグファイト（P2P・ホストが判定）: 部屋コード・共有 / コピー / QR で 2〜4 人
- ロビー（Ready・ハンガー・定型文・ホストのルール設定）とチーム戦（2 対 2）・初心者保護

## 0.4.0（2026-10-30）
