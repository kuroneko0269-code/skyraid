# SkyRaid: Kaiju Front — ゲーム仕様書 v0.1

## 1. コンセプト

- ブラウザで動く、見た目が綺麗なアーケード寄り3Dフライトシューティング
- 1人: ミッションを遊んで報酬を集め、機体を強化する
- 2〜4人: PvPドッグファイト、巨大怪獣との協力レイド
- 10分遊んで気持ちいい「飛行感」が最優先。リアル志向のシミュレーターではない

## 2. 対象環境

- デスクトップブラウザ（Chrome / Edge / Safari / Firefox 最新）
- スマホブラウザ（iOS Safari / Android Chrome）: タッチ操作対応、画質は自動で落とす
- 同時プレイ 1〜4人
- 運用コストはゼロを目標（静的配信 + P2P）

## 4. 飛行モデル（アーケード）

- 操作: ピッチ / ロール / ヨー / スロットル。失速あり、エンジン出力で回復
- 速度域: 最低 80 / 巡航 250 / 最高 400（単位はゲーム内の m/s 相当、`data/aircraft.ts` で定義）
- 地面・海面に衝突で撃墜。高度上限で押し戻し
- アフターバーナー: 一時加速。ゲージ消費
- 機体ごとに「速度 / 旋回 / 耐久 / 積載」の4パラメータで差をつける
- オートレベル（手を離すと水平に戻る）を初期ONにし、設定でOFF可能

#### 決めた数値の意味（1-1。値は `src/data/aircraft.ts` 初期機 / `src/data/flight.ts`）

- 速度は進行方向のスカラー。横滑りなし。姿勢はクォータニオン（前方 -Z・上 +Y・右 +X）
- `speed.stall` 80: これを下回ると失速。`stall.range` 30 下（50）で失速の効果が最大
- `speed.cruise` 250: 起動・リセット時の速度。スロットル初期値はこれを水平で保つ値（約 0.70）
- `speed.idle` 60: スロットル 0 で落ち着く速度。失速より低いので、絞り続けると失速する
- `speed.military` 330: スロットル 1 で落ち着く速度
- `speed.afterburner` 400: アフターバーナー中に落ち着く速度（最高速度）
- `speed.limit` 460: 降下で到達できる絶対上限
- `speed.response` 0.45 / `afterburnerResponse` 0.9: 目標速度へ近づく速さ（1/秒）
- `speed.maxAccel` 15 / `afterburnerMaxAccel` 35 / `maxDecel` 20: エンジンによる加減速の上限（m/s²）。加速上限が重力の効き（約 34）より小さいので、垂直上昇は必ず減速して失速に至る
- `gravitySpeedScale` 3.5: 重力（9.8）が速度に効く倍率。上昇で減速・降下で加速を誇張する（巡航から 30° 上昇 2 秒で約 −23 m/s）
- `rates.pitch` 75 / `roll` 200 / `yaw` 22: 旋回係数 1.0 のときの最大角速度（度/秒）。巡航で宙返り 1 周が約 5 秒
- `turnCurve`: 速度→旋回係数の折れ線。0:0.2 / 80:0.35 / 180:0.9 / 220〜300:1.0 / 400:0.7 / 460:0.55（低速で鈍く、巡航付近で最大、超高速で再び鈍る）
- `rates.rollSpeedSensitivity` 0.5: ロールが速度の影響を受ける割合（ピッチの半分）
- `rateResponse` 9: 入力から角速度が立ち上がる速さ（1/秒）。約 0.1 秒の「重さ」
- `stall.minAuthority` 0.3: 失速最大時の操舵の効き
- `stall.noseDropRate` 55: 失速最大時に機首が真下へ向く角速度（度/秒）
- `stall.sinkSpeed` 18: 失速最大時の沈下速度（m/s）
- `autoLevel.gain` 1.2 / `maxRate` 50: ピッチ・ロール入力がないとき、バンク角×1.2（最大 50 度/秒）で水平に戻す。45° からおよそ 3 秒
- `autoLevel.maxNoseVertical` 0.85: 機首が真上・真下に近い（約 58° 以上）ときはオートレベルを効かせない
- `bankTurnRate` 12: バンク 90° で機首が自然に横へ向く角速度（度/秒）
- `afterburner.durationSeconds` 6 / `rechargeSeconds` 10 / `rechargeDelaySeconds` 1 / `restartThreshold` 0.15: 満タンで 6 秒使える。離して 1 秒後から 10 秒で満タン。空にしたら 15% まで回復するまで再点火できない
- `ceiling.start` 3000 / `end` 3500 / `pushRate` 60: 3000m から機首を押し下げ始め、3500m で最大・それ以上は上がれない
- `groundAltitude` 0 / `spawn.position.y` 300: 地表（島の上は地形の高さ、海の上は海面 0。1-3 から）以下で衝突し、墜落地点の地表から 300m 上空に初期姿勢でリセット。`groundAltitude` は地形を渡さないとき（テスト等）の地面の高さ
- `throttleRate` 0.6: Shift / Z でスロットルが 1 秒に変わる量
- 操作設定の切替（設定画面ができるまでの暫定）: URL に `?autolevel=off` でオートレベル OFF、`?invert` でピッチ反転（W = 機首上げ）
- 開発用: `?skipTitle` でタイトル・モード選択を飛ばして起動直後からフリーフライト（他のパラメータと併用可）

#### タッチ・ゲームパッドの決めた数値（1-5。値は `src/data/touch.ts` / `src/data/gamepad.ts` / `src/data/input.ts`）

- タッチ操作は主ポインタが指（`pointer: coarse`）の端末で自動表示。ポーズメニューの設定「タッチ」で 自動 / 表示 / 非表示 を選べ、localStorage（`skyraid.touchControls`）に保存
- 仮想スティック: 画面左 45%・上 25% より下のどこに触れてもそこが中心。指 64px 移動で最大、デッドゾーンは半径の 12%（約 8px）。デッドゾーンの外側は 0〜1 に引き伸ばす（半径方向）
- ボタン: 64px（機銃のみ 80px）、間隔 12px。ヨーボタン 56px。画面端から 16px + safe-area
- スロットル: 幅 56px、高さは画面の 55% と 240px の小さい方。触れた位置の値（上端 = 1）になり、離しても保持。キーボード等で変えたスロットルも表示に反映
- ゲームパッド: スティックのデッドゾーン 0.15（半径方向）、トリガー 0.05。接続（`gamepadconnected`）で自動有効、最初に見つかったパッドを使う
- 連続値をボタン扱いするしきい値: 0.5 以上で押下、0.35 未満で離す（ヒステリシス）
- 系統（キーボード・タッチ・パッド）の軸の値は足して ±1 で頭打ち。キーボードは ±1 のまま

### カメラ

- 三人称追従（デフォルト）。速度で画角とカメラ距離が変わる
- C キーで「追従」⇄「固定後方」（スプリングなしで機体に完全追従）を切替

#### 決めた数値の意味（1-2。値は `src/data/camera.ts`）

- 位置・注視点・上方向はそれぞれ別の臨界減衰スプリング（行き過ぎなし）で、機体位置からのオフセットに追従する。固有角振動数 `positionStiffness` 8 / `lookStiffness` 14 / `upStiffness` 5（1/秒）。追従遅れはおよそ 2 / 値 秒（位置 0.25 秒・注視点 0.14 秒・ロール 0.4 秒）
- `distanceCurve`: 速度→後方距離（m）。80:22 / 250:24 / 400:28 / 460:29。巡航で 1-1 と同じ 24m
- `fovCurve`: 速度→垂直画角（度）。80:57 / 250:60 / 400:70 / 460:73。巡航で 1-1 と同じ 60°
- `afterburnerFovBoost` 5 / `afterburnerDistanceBoost` 2 / `afterburnerResponse` 4: アフターバーナー点火中に画角 +5°・距離 +2m を上乗せし、約 0.25 秒で立ち上がる。速度が上がり切る（約 4 秒）前に「速くなった」ことを伝える。最高速 400 で画角 75°
- `height` 6 / `lookAhead` 30: 機体の上方向 6m に置き、機首の前方 30m を見る（機体基準なので宙返り・背面でも崩れない）
- `turnLeadGain` 6 / `turnLeadMax` 8: 旋回中は注視点を「機首が向かう側」へ 角速度（rad/s）× 6m、最大 8m ずらす。巡航の全力ピッチで機体は画面中央から約 20° 下に来る
- `fixed`: 固定後方の距離 24 / 高さ 6 / 注視点 30。画角は速度の折れ線のみ
- `minHeightAboveGround` 3: カメラは地面から 3m より下へ行かない
- `shake.stallAmplitude` 0.25 / `impactAmplitude` 1.2 / `impactDecay` 3 / `frequency` 9: 失速度合いに比例した揺れ（最大 0.25m）、地面衝突で 1.2m の揺れが 1 秒で約 5% まで減衰。振幅を 0 にすると無効
- コックピット視点（フェーズ4以降）
- ミサイル発射後 1 秒間、任意でミサイルカメラ

## 5. 戦闘

### 武装
- 機銃: 弾数無限、熱ゲージ、近距離向け
- 誘導ミサイル: ロックオン制。弾数制限、補給はミッション間
- 無誘導ロケット / 爆弾: 対地・対怪獣向け（フェーズ2後半）
- フレア: ミサイル回避。回数制限

#### 機銃の決めた数値（2-1。値は `src/data/weapons.ts` / 的は `src/data/targets.ts` / 演出は `src/data/effects.ts`）

- 操作: 機銃（Space / パッド RB / タッチ GUN）を押している間連射。弾数は無限
- 連射 `fireRate` 15 発/秒。押した瞬間に 1 発目が出る。発射タイミングはステップの途中でも正確に（撃った瞬間からステップ終わりまでの分だけ弾を先に進める）
- 弾速: 機首方向に `muzzleSpeed` 900 m/s + 機体の速度（巡航で約 1150 m/s）。銃口は機体ローカル (0, −0.3, −7.5)
- 射程 `range` 1500m（ワールドでの移動距離）。巡航で約 1.3 秒飛んで消える
- 重力 `gravity` 9.8 m/s²。射程いっぱいで約 8m 落ちる
- ばらつき `spreadDeg` 0.3°（機首方向から最大のずれ）
- ダメージ `damage` 10 / 発
- 熱ゲージ: 1 発 +1/60（`heat.perShot`）。撃ち続けて 60 発（4 秒）で上限 → オーバーヒート。最後に撃ってから 0.3 秒（`coolDelay`）で 0.4/秒（`coolRate`）で冷え始める（満タンから 0 まで 2.5 秒）。オーバーヒート中は待ちなしで冷え、0.5（`recoverBelow`）まで冷えると解除（約 1.25 秒）
- 当たり判定: 固定ステップ（60Hz）ごとに、弾の前ステップ位置 → 現在位置の線分と対象の球（半径は対象ごと）の交差。1 ステップ約 19m 進んでもすり抜けない。複数に当たる場合は手前の 1 つ。地面・海面に当たった弾も消える
- 弾はプール（`maxBullets` 256）で使い回す。満杯のときは撃っても弾が出ない（通常の連射では 20 発前後しか同時に飛ばない）
- 的（風船）: 島の上空に 10 個。HP 120（12 発で撃墜）、当たり判定の半径 8m（見た目 6m より少し大きく）。地表から 200〜300m に置き、振幅 8m・周期 6 秒で上下（位相は的ごとにずらす）。撃墜から 10 秒後、出現候補 16 地点のうち「どの的もいない・直前とも違う」地点へ HP 満タンで再出現。被弾すると 0.08 秒白く光る
- 演出: 曳光弾は長さ 14m のオレンジの棒（太さ 0.35m、遠くでは 1080p で約 2.5px を下限）。マズルフラッシュは 1 発ごとに 2 描画フレーム。火花は的に当たると 8 個・地面で 4 個（0.18〜0.35 秒で縮んで消える）。撃墜で破片 6〜8 個が飛び散り 1.5 秒で消える（最後の 35% で縮む）
- 描画: 弾・火花・破片・的はそれぞれ InstancedMesh 1 つ。数によらず増える draw call は最大 5（マズルフラッシュ含む）
- HUD: 左のゲージ列に「GUN」熱ゲージ（オーバーヒートで赤く点滅）、命中で画面中央に白い × を 0.1 秒（`src/data/hud.ts` の `hitMarkerSeconds`）、右の高度の下に撃墜数「KILL」
- フリーフライトを始めるたびに撃墜数・弾・的をリセット。音はフェーズ4

#### ロックオン・ミサイル・フレアの決めた数値（2-2。値は `src/data/weapons.ts` / ドローンは `src/data/targets.ts` / 演出は `src/data/effects.ts` / HUD は `src/data/hud.ts`）

- 索敵: 距離 5000m・機首から ±60° の対象（的・ドローン）が候補。既定の選択は機首に最も近い（角度が最小の）候補。Tab / パッド Y で機首に近い順に次の候補へ（末尾の次は先頭）。タッチは HUD の対象をタップ（48px 以内で最も近いもの）。選択中の対象は視野の外へ出ても 6000m（`keepRange`）までは選んだまま。撃墜・消滅・範囲外で外れたら自動で次の候補へ
- ロック: ロック円錐（機首 ±12°・2500m 以内）に入っている間ゲージが 1.2 秒で満タン → ロック完了。外れると満タンから 0.8 秒で 0 に戻る（戻ればそこから再開）。対象を切り替えるとやり直し
- ミサイル（F / パッド A / タッチ MSL）: 初期機 4 発、連射間隔 0.4 秒。補給はミッション間（今はフリーフライト開始時に満タン）。ロック完了で撃つと誘導、未完了なら無誘導で直進。発射位置は左右の翼下 (±2.6, −0.6, 0.5) を交互
  - 初速は母機の速度。220 m/s² で加速し最高 700 m/s。燃焼 5 秒（約 3km）、寿命 10 秒
  - 発射後 0.5 秒は直進して母機から離れ、その後燃焼中だけ誘導。誘導は比例航法の簡易版: 視線角速度 ω = (r × v相対) / |r|² の 4 倍（航法定数）で速度の向きを回す。最大旋回率 30°/秒で頭打ち
  - シーカーの視野 ±50°。目標がその外へ出たら見失って直進。燃焼後は誘導せず、重力 9.8 と空気抵抗 0.08/秒で落ちる
  - 近接信管: 発射 0.3 秒後から、1 ステップの移動の線分が「対象の当たり判定の半径 + 6m」の球にかかったら、線分上で対象に最も近い点で起爆。地面・海面に当たっても起爆。寿命切れは起爆せず消える
  - 範囲ダメージ: 半径 25m。爆心から対象の表面までの距離 d に対して 150 × (1 − 0.7 × d/25)（中心 150・縁 45・外は 0）。範囲内のすべての対象に入る。的（HP 120）・ドローン（HP 100）は信管が働けば 1 発
- フレア（X / パッド B / タッチ FLR）: 6 回、クールダウン 2 秒。1 回に 4 個を尾部の下 (0, −0.6, 4.5) から後ろ・下・左右へ扇形に 40 m/s で放ち、母機の速度を引き継いで空気抵抗 0.6/秒・重力 4 で 3 秒漂う
  - 誘導中のミサイルは、シーカーの視野（±50°）内・2000m 以内に別の陣営のフレアを見ると、その放出 1 回につき 1 回だけ 60% の確率で目標をフレアに乗り換える。フレアが消えると目標を失って直進。自分の陣営のフレアには釣られない（敵機のミサイルは 2-3 から。動作はテストで保証）
- 練習用ドローン: 3 機が島の中心を半径 2400 / 2000 / 1700m・高度 800 / 700 / 950m で反時計回りに 120 m/s で周回（固定経路、AI は 2-3）。HP 100、当たり判定の半径 7m（翼幅 9m）。撃墜から 15 秒後に同じ軌道の、その時点の位置へ再出現。描画は進行方向を向き、円の内側へ tan φ = v²/(r g)（約 31〜41°）バンク
- 機銃の予測照準点: 弾の速さ（機速 + 900）で選択中の対象に当たる時間 t を |D + V t| = s t から求め、対象の t 秒後の位置 + 落下分 g t²/2 だけ上を照準点とする。射程（1500m を飛ぶ時間）内のときだけ小さな ○ を出す。カメラの視差を補正してあり、進行方向マーカーを ○ に重ねて撃つと当たる
- HUD: 索敵範囲の対象に四角（最大 12 個の DOM を使い回す）、選択中の対象にひし形とその下に距離（1000m 未満は m、以上は km 小数 1 桁）。ロック進行中は 3 倍の円がひし形まで縮み、完了で赤い枠と「LOCK」。画面外の選択対象は画面端（40px 内側）に方向を示す三角。左のゲージ列の右に残弾「MSL 4 / FLR 6」（0 で赤、フレアのクールダウン中は薄く）
- 演出: ミサイル本体は 3.6m × 0.35m の白い箱。燃焼中は尾部から 1/50 秒（ゲーム内時間）ごとに煙の玉を出し、0.9 秒で直径 1.4m → 6m に広がって消える（上限 400 個）。フレアは発光する点（1.6m、遠くでは画面上の大きさを下限に、ちらつく）。起爆は直径 16m の閃光（0.35 秒で縮む）と火花 24 個、撃墜なら 2-1 の破片
- 描画: ミサイル本体・煙・フレア・閃光はそれぞれ InstancedMesh 1 つ。ミサイル 8 発 + 煙 352 個 + フレア + 閃光で増える draw call は 4。ドローンは 1

### ダメージ
- 機体HP。0で撃墜、リスポーンの有無はモード依存
- 怪獣は部位HP（頭・背・脚・尾）。部位破壊でダウンや攻撃封じ

### 敵機AI（フェーズ2）
- 状態: 巡航 → 追尾 → 攻撃 → 回避 → 離脱
- 難易度は反応時間・命中率・ミサイル使用頻度で調整

## 6. ミッション（キャンペーン）

- 定義はデータ駆動（`src/data/missions.ts`）。各ミッションは「出現物」「目標」「成功/失敗条件」「報酬」
- 目標タイプ: 撃墜数 / 護衛 / 破壊 / リング通過 / 生存時間 / 怪獣撃破
- 評価: クリア時間と被弾でS〜C。ランクで報酬が増える
- 初期ミッション（5本）:
  1. 訓練: リングを10個通過
  2. 初陣: 敵機3機撃墜
  3. 護衛: 輸送機を目的地まで
  4. 爆撃: 地上目標4つ破壊
  5. 遭遇: 怪獣が出現、一定ダメージで撤退（レイドの導入）

## 7. 成長と経済

- 通貨: クレジット（ミッション報酬）
- 強化: エンジン / 機体 / 武装 / 電子装備 の4系統、各Lv1〜5
- 機体購入: 初期機 + 3機（軽量・バランス・重武装）
- アイテム: ドロップするパーツ。レア強化に必要（フェーズ3後半）
- スキン・デカール: 見た目のみ（フェーズ7）
- セーブ: localStorage にJSON。スキーマはバージョン番号付きで移行可能に

## 8. 怪獣レイド

- 怪獣はオリジナルデザイン（実在IPは使わない）。初代は「海から上陸する二足歩行の巨獣」
- 高さ 150m 想定。市街地マップで建物を壊しながら進む
- 攻撃: 薙ぎ払い（周囲）、咆哮（スタン）、熱線（直線、予兆あり）、投擲（対空）
- フェーズ制: HP 70% / 40% で行動が変化。最終フェーズは制限時間
- 協力要素: 部位を同時に攻撃すると「ブレイク」で大ダメージ。誰かがタゲを取っている間に背面を狙う
- 報酬: 全員に配布、貢献度で差をつけない（協力を優先）

## 9. マルチプレイ

- 方式: PeerJS による P2P。部屋コード（6文字）で接続
- ホストが正。クライアントは入力を送信し、状態を受信して補間表示
- 送信頻度: 入力 30Hz、状態 15Hz。位置・姿勢・速度・HP・弾
- 当たり判定はホスト側で決定。クライアント側は演出のみ
- ホスト切断時はセッション終了（再接続は将来課題）
- 遅延対策: デッドレコニング（速度で外挿）+ スナップ補正

## 10. ビジュアル

- 目標: HDRスカイ、PBRマテリアル、水面、ブルーム、簡易大気散乱、雲（ビルボード）
- 品質設定: 低 / 中 / 高（自動判定 + 手動）
- マップ: 初期は「海岸と島」1枚。後に「市街地（レイド用）」「峡谷（レース用）」
- プレースホルダー期間はプリミティブで進め、フェーズ4で差し替え

#### 島・海・空の決めた数値（1-3。値は `src/data/terrain.ts`、画質は `src/data/quality.ts`）

- 島: 8km 四方（原点中心）を 4×4 チャンク（一辺 2km）に分けて描く。外側は海面だけ。シード `20261029` の simplex ノイズで決まり、毎回同じ形
- 形: 中心からの距離を海岸線の半径（平均 2900m、ノイズで ±18%）で割った t（中心 0・海岸 1）で決める。山 `500 × exp(−4t²)` + 平地 `80 × (1 − t)`（海岸でちょうど 0）+ 丘（fBm、振幅 70m）+ 尾根（リッジノイズ、振幅 90m、山の上ほど強い）。最高点は約 600m（実測 609m）。海岸の手前（t 0.7〜1）で丘を消して砂浜をなだらかにする。海岸の外は t 1〜1.35 で海底へ下がり、深さ 60m で平ら
- 色（頂点カラー）: 海底 → 砂（海面〜4m）→ 草地 → 森（90m 付近）→ 岩（260m 付近）→ 雪（470m 付近）。境目は ±25m で混ぜる。法線の y が 0.75（約 41°）より急な斜面は岩、雪は急斜面に積もらない。頂点ごとに明るさを ±6% ばらつかせる
- LOD: チャンクの分割数 128 / 64 / 32 / 16（約 16 / 31 / 63 / 125m 間隔）。カメラからチャンクの箱（高さの範囲込み）までの距離が 描画距離 × 0.12 / 0.3 / 0.6 未満でそれぞれの段、描画距離までは最も粗い段、その先は描かない。粗くするときだけ 100m 余分に待つ（境目でのちらつき防止）。画質「低」は 64 分割から（最も細かい段を使わない）
- LOD の違う隣とのひび割れは、細かい側の縁の頂点を粗い側の直線上に寄せて塞ぐ
- 衝突判定は描画メッシュではなく高さ関数そのもの（`getGroundHeight`）。メッシュは格子の間を直線でつなぐので、低画質では見た目と数 m ずれうる
- 画質「低」の海面は簡略版: 頂点の波は 1 本目（振幅 0.9m・波長 260m）だけ、さざ波なし、水の色とフレネル・空の反射は頂点で計算して補間（太陽の照り返しだけ画素ごと）。スマホで 30fps を確保するため（`OCEAN_CONFIG.simple` / `QualityPreset.oceanSimple`）
- 海面: 高さ 0 の平面（一辺 = 描画距離 × 2.5、64 分割）をカメラの真下に格子単位で追従。3 つの正弦波（振幅 0.9 / 0.6 / 0.35m、波長 260 / 170 / 110m）で頂点を上下させ、波長 23 / 13 / 7.5m のさざ波で法線だけ揺らす（150〜700m で消してちらつきを防ぐ）。色は真下が水の色、浅い角度ほど空の反射（Schlick のフレネル、反射率 0.85）+ 太陽の照り返し
- 空: 天頂 `#2f6bb8` → 地平線 `#bcd3e6`（地平線からの高さ^0.55 で混ぜる）。地平線より下は地平線の色。霧と背景の色も地平線の色にして、海の果て・遠くの山が空に溶けるようにする。霧の範囲は従来どおり描画距離 × 0.1〜0.7
- 太陽: 方位 40°（初期の進行方向 −Z から右回り）、仰角 32°、視半径 1.2° の円盤 + にじみ。平行光源も同じ向き・強さ 2.0（1-1 と同じ）
- 起動位置: (0, 500, 4500)。島の沖合（海岸から約 1.9km）、高度 500m で −Z（島の方向）へ巡航速度。画質「低」の霧（2100m で消える）でも海岸が見える距離。そのまま水平に飛ぶと約 16 秒で山の中腹（高度 500m）に当たる

## 11. UI

- タイトル → モード選択 → （ハンガー）→ ブリーフィング → プレイ → リザルト
- HUD: 速度、高度、HP、武装残弾、ロックオン枠、レーダー、ミッション目標
- 全画面DOM。文字は日本語・英語の2言語（i18n JSON）

#### HUD の決めた数値（1-4。値は `src/data/hud.ts`）

- 色はシアン `rgba(110, 240, 255, 0.85)` の 1 色 + 警告の赤。箱・レーダーの背景は半透明で背景が見える。フォントは Web フォントなし（数字は等幅のシステムフォント、ラベルは system-ui）
- 中央: ピッチラダー。10° ごと ±90°、機首上げ側は実線・機首下げ側は破線、数字は絶対値。1° = 8px（狭い画面は 5px）。楕円の窓（260×280px、狭い画面 180×170px）で切り抜き、ロールと逆に回す（右バンクで反時計回り）。画面中央が機体のピッチ。窓は画面中央に固定（カメラの見え方と厳密には一致しない、非コンフォーマル）
- 進行方向マーカー: 機首方向 1000m 先の点をカメラで投影した位置（横滑りなしなので進行方向 = 機首方向）。追従カメラの遅れ・旋回の先読みで画面中央から動く
- 左（ラダーの左隣）: 速度（m/s 相当、整数に丸め）、スロットル位置、アフターバーナーゲージ（点火中は濃く、使い切って再点火待ちは薄く）
- 右（ラダーの右隣）: 高度（海面基準、m、整数に丸め）。地表（島の上は地形、海の上は海面）との距離が 100m 未満で高度の箱を赤く点滅させ、下に「PULL UP」を点滅表示
- 失速（`FlightState.stall` > 0）で「STALL」をラダーの窓の上端に赤く点滅表示。点滅は 0.8 秒周期
- 下: 円形レーダー（機首方向が上）。半径 8000m（起動位置の沖合 4.5km から島が収まる）。直径 120px（狭い画面 88px）。自機は中央の三角、島の中心は四角、範囲外は縁に中抜きで表示。敵は 2-x で追加
- 狭い画面: 幅 760px 以下または高さ 480px 以下（スマホ横画面）で、ラダー・文字・レーダーを縮小
- 配置: 速度・高度の箱はラダーの両脇（画面端はタッチのヨーボタン・スティック・ボタン群が使う）。タッチ操作中はレーダーを「スティックの待機位置の右端」と「右下のボタン群の左端」の間の中央に寄せる（画面中央から左へ 44px）
- 更新: 数値テキストは表示文字列が変わったときだけ、ラダーは角度が 0.1° 以上、マーカーは 0.5px 以上、ゲージは 0.005 以上変わったときだけ書き換える。HUD を隠している間は計算もしない
- 表示切替: H キー、またはポーズメニューの設定の「HUD ON/OFF」。初期は表示、保存はしない

#### タイトル・モード選択・ポーズの決めた数値（1-6。値は `src/data/screens.ts`）

- 画面の状態: 読み込み中（boot）→ タイトル → モード選択 → 飛行 ⇄ ポーズ → タイトル。モード選択からタイトルへ戻れる。`?skipTitle` は読み込み中 → 飛行。遷移表は `src/core/game-state.ts`
- 固定ステップ更新（ゲームの時間）は飛行中だけ進める。ポーズ・タイトル・モード選択では止め、止めている間の時間は貯めない（再開しても一気に進まない）。描画は続けるが、ポーズ中は機体・カメラ・海の波も止まる
- 画面遷移は CSS transition のフェード 0.3 秒。カメラが切り替わる遷移（モード選択 → 飛行、ポーズ → タイトル）は一瞬黒にして 0.3 秒で明ける暗転で隠す
- 読み込み中: 起動時に `BOOT_TASKS`（`src/core/boot.ts`）を順に Promise で待ち、進捗バーを出す。アセットはまだ無いので即完了
- タイトル: 背景は実際のシーン。デモカメラが島の中心の周りを半径 3600m・高度 600m で 150 秒に 1 周（約 2.4°/秒）し、島の中心の高さ 200m を見る。開始位置は起動位置と同じ南側（+Z）。ロゴは「SkyRaid」+「KAIJU FRONT」のテキストと CSS のみ（画像・Web フォントなし）。画面のどこをタップ / Enter で開始
- モード選択: フリーフライトのみ選べる。キャンペーン・PvP・レイドは「近日」と表示して押せない。Esc / 「← タイトルへ」で戻る
- フリーフライト: モード選択から入るたびに起動位置・巡航速度から始める。墜落リセットは従来どおり
- ポーズ: Esc / パッドの Start / 右上の ⏸ ボタン（一辺 44px。タッチ操作中は右上のヨーボタンの左隣、間隔 12px）。メニューは「再開」「設定 ▼」（画質・タッチ・HUD・全画面。開閉できる）「タイトルへ」。Esc / Start でも再開
- 飛行中の画面上部の設定バーは廃止し、ポーズメニューの設定に移した。F3（デバッグ表示）と H（HUD）はメニュー中も効く
- タイトル・モード選択では機体・HUD・タッチ操作を隠す。ポーズ中は HUD を残し、タッチ操作は隠す
