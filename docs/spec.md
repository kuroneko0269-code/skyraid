# SkyRaid: Titan Skies — ゲーム仕様書 v0.1

## 1. コンセプト

- ブラウザで動く、見た目が綺麗なアーケード寄り3Dフライトシューティング
- 1人: ミッションを遊んで報酬を集め、機体を強化する
- 2〜4人: PvPドッグファイト、巨大怪獣との協力レイド
- 10分遊んで気持ちいい「飛行感」が最優先。リアル志向のシミュレーターではない

## 2. 対象環境

- デスクトップブラウザ（Chrome / Edge / Safari / Firefox 最新）
- スマホブラウザ（iOS Safari / Android Chrome）: タッチ操作対応、画質は自動で落とす
- 同時プレイ 1〜4人
- 運用コストはゼロを目標（静的配信 + P2P）

## 4. 飛行モデル（アーケード）

- 操作: ピッチ / ロール / ヨー / スロットル。失速あり、エンジン出力で回復
- 速度域: 最低 80 / 巡航 250 / 最高 400（単位はゲーム内の m/s 相当、`data/aircraft.ts` で定義）
- 地面・海面に衝突で撃墜。高度上限で押し戻し
- アフターバーナー: 一時加速。ゲージ消費
- 機体ごとに「速度 / 旋回 / 耐久 / 積載」の4パラメータで差をつける
- オートレベル（手を離すと水平に戻る）を初期ONにし、設定でOFF可能

#### 決めた数値の意味（1-1。値は `src/data/aircraft.ts` 初期機 / `src/data/flight.ts`）

- 速度は進行方向のスカラー。横滑りなし。姿勢はクォータニオン（前方 -Z・上 +Y・右 +X）
- `speed.stall` 80: これを下回ると失速。`stall.range` 30 下（50）で失速の効果が最大
- `speed.cruise` 250: 起動・リセット時の速度。スロットル初期値はこれを水平で保つ値（約 0.70）
- `speed.idle` 60: スロットル 0 で落ち着く速度。失速より低いので、絞り続けると失速する
- `speed.military` 330: スロットル 1 で落ち着く速度
- `speed.afterburner` 400: アフターバーナー中に落ち着く速度（最高速度）
- `speed.limit` 460: 降下で到達できる絶対上限
- `speed.response` 0.45 / `afterburnerResponse` 0.9: 目標速度へ近づく速さ（1/秒）
- `speed.maxAccel` 15 / `afterburnerMaxAccel` 35 / `maxDecel` 20: エンジンによる加減速の上限（m/s²）。加速上限が重力の効き（約 34）より小さいので、垂直上昇は必ず減速して失速に至る
- `gravitySpeedScale` 3.5: 重力（9.8）が速度に効く倍率。上昇で減速・降下で加速を誇張する（巡航から 30° 上昇 2 秒で約 −23 m/s）
- `rates.pitch` 75 / `roll` 200 / `yaw` 22: 旋回係数 1.0 のときの最大角速度（度/秒）。巡航で宙返り 1 周が約 5 秒
- `turnCurve`: 速度→旋回係数の折れ線。0:0.2 / 80:0.35 / 180:0.9 / 220〜300:1.0 / 400:0.7 / 460:0.55（低速で鈍く、巡航付近で最大、超高速で再び鈍る）
- `rates.rollSpeedSensitivity` 0.5: ロールが速度の影響を受ける割合（ピッチの半分）
- `rateResponse` 9: 入力から角速度が立ち上がる速さ（1/秒）。約 0.1 秒の「重さ」
- `stall.minAuthority` 0.3: 失速最大時の操舵の効き
- `stall.noseDropRate` 55: 失速最大時に機首が真下へ向く角速度（度/秒）
- `stall.sinkSpeed` 18: 失速最大時の沈下速度（m/s）
- `autoLevel.gain` 1.2 / `maxRate` 50: ピッチ・ロール入力がないとき、バンク角×1.2（最大 50 度/秒）で水平に戻す。45° からおよそ 3 秒
- `autoLevel.maxNoseVertical` 0.85: 機首が真上・真下に近い（約 58° 以上）ときはオートレベルを効かせない
- `bankTurnRate` 12: バンク 90° で機首が自然に横へ向く角速度（度/秒）
- `afterburner.durationSeconds` 6 / `rechargeSeconds` 10 / `rechargeDelaySeconds` 1 / `restartThreshold` 0.15: 満タンで 6 秒使える。離して 1 秒後から 10 秒で満タン。空にしたら 15% まで回復するまで再点火できない
- `ceiling.start` 3000 / `end` 3500 / `pushRate` 60: 3000m から機首を押し下げ始め、3500m で最大・それ以上は上がれない
- `groundAltitude` 0 / `spawn.position.y` 300: 地表（島の上は地形の高さ、海の上は海面 0。1-3 から）以下で衝突し、墜落地点の地表から 300m 上空に初期姿勢でリセット。`groundAltitude` は地形を渡さないとき（テスト等）の地面の高さ
- `throttleRate` 0.6: Shift / Z でスロットルが 1 秒に変わる量
- 操作設定の切替（設定画面ができるまでの暫定）: URL に `?autolevel=off` でオートレベル OFF、`?invert` でピッチ反転（W = 機首上げ）
- 開発用: `?skipTitle` でタイトル・モード選択を飛ばして起動直後からフリーフライト（他のパラメータと併用可）

#### タッチ・ゲームパッドの決めた数値（1-5。値は `src/data/touch.ts` / `src/data/gamepad.ts` / `src/data/input.ts`）

- タッチ操作は主ポインタが指（`pointer: coarse`）の端末で自動表示。ポーズメニューの設定「タッチ」で 自動 / 表示 / 非表示 を選べ、localStorage（`skyraid.touchControls`）に保存
- 仮想スティック: 画面左 45%・上 25% より下のどこに触れてもそこが中心。指 64px 移動で最大、デッドゾーンは半径の 12%（約 8px）。デッドゾーンの外側は 0〜1 に引き伸ばす（半径方向）
- ボタン: 64px（機銃のみ 80px）、間隔 12px。ヨーボタン 56px。画面端から 16px + safe-area
- スロットル: 幅 56px、高さは画面の 55% と 240px の小さい方。触れた位置の値（上端 = 1）になり、離しても保持。キーボード等で変えたスロットルも表示に反映
- ゲームパッド: スティックのデッドゾーン 0.15（半径方向）、トリガー 0.05。接続（`gamepadconnected`）で自動有効、最初に見つかったパッドを使う
- 連続値をボタン扱いするしきい値: 0.5 以上で押下、0.35 未満で離す（ヒステリシス）
- 系統（キーボード・タッチ・パッド）の軸の値は足して ±1 で頭打ち。キーボードは ±1 のまま

### カメラ

- 三人称追従（デフォルト）。速度で画角とカメラ距離が変わる
- C キーで「追従」⇄「固定後方」（スプリングなしで機体に完全追従）を切替

#### 決めた数値の意味（1-2。値は `src/data/camera.ts`）

- 位置・注視点・上方向はそれぞれ別の臨界減衰スプリング（行き過ぎなし）で、機体位置からのオフセットに追従する。固有角振動数 `positionStiffness` 8 / `lookStiffness` 14 / `upStiffness` 5（1/秒）。追従遅れはおよそ 2 / 値 秒（位置 0.25 秒・注視点 0.14 秒・ロール 0.4 秒）
- `distanceCurve`: 速度→後方距離（m）。80:22 / 250:24 / 400:28 / 460:29。巡航で 1-1 と同じ 24m
- `fovCurve`: 速度→垂直画角（度）。80:57 / 250:60 / 400:70 / 460:73。巡航で 1-1 と同じ 60°
- `afterburnerFovBoost` 5 / `afterburnerDistanceBoost` 2 / `afterburnerResponse` 4: アフターバーナー点火中に画角 +5°・距離 +2m を上乗せし、約 0.25 秒で立ち上がる。速度が上がり切る（約 4 秒）前に「速くなった」ことを伝える。最高速 400 で画角 75°
- `height` 6 / `lookAhead` 30: 機体の上方向 6m に置き、機首の前方 30m を見る（機体基準なので宙返り・背面でも崩れない）
- `turnLeadGain` 6 / `turnLeadMax` 8: 旋回中は注視点を「機首が向かう側」へ 角速度（rad/s）× 6m、最大 8m ずらす。巡航の全力ピッチで機体は画面中央から約 20° 下に来る
- `fixed`: 固定後方の距離 24 / 高さ 6 / 注視点 30。画角は速度の折れ線のみ
- `minHeightAboveGround` 3: カメラは地面から 3m より下へ行かない
- `shake.stallAmplitude` 0.25 / `impactAmplitude` 1.2 / `impactDecay` 3 / `frequency` 9: 失速度合いに比例した揺れ（最大 0.25m）、地面衝突で 1.2m の揺れが 1 秒で約 5% まで減衰。振幅を 0 にすると無効
- コックピット視点（フェーズ4以降）
- ミサイル発射後 1 秒間、任意でミサイルカメラ

## 5. 戦闘

### 武装
- 機銃: 弾数無限、熱ゲージ、近距離向け
- 誘導ミサイル: ロックオン制。弾数制限、補給はミッション間
- 無誘導ロケット / 爆弾: 対地・対怪獣向け（2-6。下の「無誘導兵器・地上目標・対空砲」）
- フレア: ミサイル回避。回数制限

#### 機銃の決めた数値（2-1。値は `src/data/weapons.ts` / 的は `src/data/targets.ts` / 演出は `src/data/effects.ts`）

- 操作: 機銃（Space / パッド RB / タッチ GUN）を押している間連射。弾数は無限
- 連射 `fireRate` 15 発/秒。押した瞬間に 1 発目が出る。発射タイミングはステップの途中でも正確に（撃った瞬間からステップ終わりまでの分だけ弾を先に進める）
- 弾速: 機首方向に `muzzleSpeed` 900 m/s + 機体の速度（巡航で約 1150 m/s）。銃口は機体ローカル (0, −0.3, −7.5)
- 射程 `range` 1500m（ワールドでの移動距離）。巡航で約 1.3 秒飛んで消える
- 重力 `gravity` 9.8 m/s²。射程いっぱいで約 8m 落ちる
- ばらつき `spreadDeg` 0.3°（機首方向から最大のずれ）
- ダメージ `damage` 10 / 発
- 熱ゲージ: 1 発 +1/60（`heat.perShot`）。撃ち続けて 60 発（4 秒）で上限 → オーバーヒート。最後に撃ってから 0.3 秒（`coolDelay`）で 0.4/秒（`coolRate`）で冷え始める（満タンから 0 まで 2.5 秒）。オーバーヒート中は待ちなしで冷え、0.5（`recoverBelow`）まで冷えると解除（約 1.25 秒）
- 当たり判定: 固定ステップ（60Hz）ごとに、弾の前ステップ位置 → 現在位置の線分と対象の球（半径は対象ごと）の交差。1 ステップ約 19m 進んでもすり抜けない。複数に当たる場合は手前の 1 つ。地面・海面に当たった弾も消える
- 弾はプール（`maxBullets` 256）で使い回す。満杯のときは撃っても弾が出ない（通常の連射では 20 発前後しか同時に飛ばない）
- 的（風船）: 島の上空に 10 個。HP 120（12 発で撃墜）、当たり判定の半径 8m（見た目 6m より少し大きく）。地表から 200〜300m に置き、振幅 8m・周期 6 秒で上下（位相は的ごとにずらす）。撃墜から 10 秒後、出現候補 16 地点のうち「どの的もいない・直前とも違う」地点へ HP 満タンで再出現。被弾すると 0.08 秒白く光る
- 演出: 曳光弾は長さ 14m のオレンジの棒（太さ 0.35m、遠くでは 1080p で約 2.5px を下限）。マズルフラッシュは 1 発ごとに 2 描画フレーム。火花は的に当たると 8 個・地面で 4 個（0.18〜0.35 秒で縮んで消える）。撃墜で破片 6〜8 個が飛び散り 1.5 秒で消える（最後の 35% で縮む）
- 描画: 弾・火花・破片・的はそれぞれ InstancedMesh 1 つ。数によらず増える draw call は最大 5（マズルフラッシュ含む）
- HUD: 左のゲージ列に「GUN」熱ゲージ（オーバーヒートで赤く点滅）、命中で画面中央に白い × を 0.1 秒（`src/data/hud.ts` の `hitMarkerSeconds`）、右の高度の下に撃墜数「KILL」
- フリーフライトを始めるたびに撃墜数・弾・的をリセット。音はフェーズ4

#### ロックオン・ミサイル・フレアの決めた数値（2-2。値は `src/data/weapons.ts` / ドローンは `src/data/targets.ts` / 演出は `src/data/effects.ts` / HUD は `src/data/hud.ts`）

- 索敵: 距離 5000m・機首から ±60° の対象（的・ドローン）が候補。既定の選択は機首に最も近い（角度が最小の）候補。Tab / パッド Y で機首に近い順に次の候補へ（末尾の次は先頭）。タッチは HUD の対象をタップ（48px 以内で最も近いもの）。選択中の対象は視野の外へ出ても 6000m（`keepRange`）までは選んだまま。撃墜・消滅・範囲外で外れたら自動で次の候補へ
- ロック: ロック円錐（機首 ±12°・2500m 以内）に入っている間ゲージが 1.2 秒で満タン → ロック完了。外れると満タンから 0.8 秒で 0 に戻る（戻ればそこから再開）。対象を切り替えるとやり直し
- ミサイル（F / パッド A / タッチ MSL）: 初期機 4 発、連射間隔 0.4 秒。補給はミッション間（今はフリーフライト開始時に満タン）。ロック完了で撃つと誘導、未完了なら無誘導で直進。発射位置は左右の翼下 (±2.6, −0.6, 0.5) を交互
  - 初速は母機の速度。220 m/s² で加速し最高 700 m/s。燃焼 5 秒（約 3km）、寿命 10 秒
  - 発射後 0.5 秒は直進して母機から離れ、その後燃焼中だけ誘導。誘導は比例航法の簡易版: 視線角速度 ω = (r × v相対) / |r|² の 4 倍（航法定数）で速度の向きを回す。最大旋回率 30°/秒で頭打ち
  - シーカーの視野 ±50°。目標がその外へ出たら見失って直進。燃焼後は誘導せず、重力 9.8 と空気抵抗 0.08/秒で落ちる
  - 近接信管: 発射 0.3 秒後から、1 ステップの移動の線分が「対象の当たり判定の半径 + 6m」の球にかかったら、線分上で対象に最も近い点で起爆。地面・海面に当たっても起爆。寿命切れは起爆せず消える
  - 範囲ダメージ: 半径 25m。爆心から対象の表面までの距離 d に対して 150 × (1 − 0.7 × d/25)（中心 150・縁 45・外は 0）。範囲内のすべての対象に入る。的（HP 120）・ドローン（HP 100）は信管が働けば 1 発
- フレア（X / パッド B / タッチ FLR）: 6 回、クールダウン 2 秒。1 回に 4 個を尾部の下 (0, −0.6, 4.5) から後ろ・下・左右へ扇形に 40 m/s で放ち、母機の速度を引き継いで空気抵抗 0.6/秒・重力 4 で 3 秒漂う
  - 誘導中のミサイルは、シーカーの視野（±50°）内・2000m 以内に別の陣営のフレアを見ると、その放出 1 回につき 1 回だけ 60% の確率で目標をフレアに乗り換える。フレアが消えると目標を失って直進。自分の陣営のフレアには釣られない（敵機のミサイルにはプレイヤーのフレアが効き、敵機のフレアは効かない。2-3）
- 練習用ドローン: 3 機が島の中心を半径 2400 / 2000 / 1700m・高度 800 / 700 / 950m で反時計回りに 120 m/s で周回（固定経路。AI で飛ぶのは敵機（2-3））。HP 100、当たり判定の半径 7m（翼幅 9m）。撃墜から 15 秒後に同じ軌道の、その時点の位置へ再出現。描画は進行方向を向き、円の内側へ tan φ = v²/(r g)（約 31〜41°）バンク
- 機銃の予測照準点: 弾の速さ（機速 + 900）で選択中の対象に当たる時間 t を |D + V t| = s t から求め、対象の t 秒後の位置 + 落下分 g t²/2 だけ上を照準点とする。射程（1500m を飛ぶ時間）内のときだけ小さな ○ を出す。カメラの視差を補正してあり、進行方向マーカーを ○ に重ねて撃つと当たる
- HUD: 索敵範囲の対象に四角（最大 12 個の DOM を使い回す）、選択中の対象にひし形とその下に距離（1000m 未満は m、以上は km 小数 1 桁）。ロック進行中は 3 倍の円がひし形まで縮み、完了で赤い枠と「LOCK」。画面外の選択対象は画面端（40px 内側）に方向を示す三角。左のゲージ列の右に残弾「MSL 4 / FLR 6」（0 で赤、フレアのクールダウン中は薄く）
- 演出: ミサイル本体は 3.6m × 0.35m の白い箱。燃焼中は尾部から 1/50 秒（ゲーム内時間）ごとに煙の玉を出し、0.9 秒で直径 1.4m → 6m に広がって消える（上限 400 個）。フレアは発光する点（1.6m、遠くでは画面上の大きさを下限に、ちらつく）。起爆は直径 16m の閃光（0.35 秒で縮む）と火花 24 個、撃墜なら 2-1 の破片
- 描画: ミサイル本体・煙・フレア・閃光はそれぞれ InstancedMesh 1 つ。ミサイル 8 発 + 煙 352 個 + フレア + 閃光で増える draw call は 4。ドローンは 1

### ダメージ
- 機体HP。0で撃墜、リスポーンの有無はモード依存

### 敵機AI（2-3）
- 状態: 巡航 → 追尾 → 攻撃 → 回避 → 離脱
- 難易度は反応時間・命中率・ミサイル使用頻度・最大 G で調整

#### 敵機 AI の決めた数値（2-3。値は `src/data/ai.ts`、敵機は `src/data/aircraft.ts` の `ENEMY_FIGHTER`、敵の機銃は `src/data/weapons.ts` の `ENEMY_GUN_CONFIG`）

- 物理はプレイヤーと共通: 敵機も `Aircraft`（1-1 の飛行モデル、オートレベルなし）で飛び、AI は毎ステップ pitch / roll / yaw / スロットル位置 / アフターバーナー / 機銃・ミサイル・フレアの「入力値」を出すだけ（`src/ai/`、Three.js 非依存）
- 判断と操縦: 状態の遷移・発射の判断・相手の見直しは反応時間（`reactionSeconds`）ごと。間の相手の位置は「判断のときの位置 + 速度 × 経過時間」で見積もる。操縦（機首を狙いへ向ける）は毎ステップ
  - 操縦は「狙いが機首から 8° 以上離れていればロールで狙いを頭上に置いてピッチで引く、近ければピッチとヨーで合わせる」。比例（ロール 3・ピッチ 4・ヨー 3 / rad）+ 角速度のダンピング + 狙いの向きの回転速度のフィードフォワード（旋回する相手を遅れなく追う）。下向き（マイナス G）は上限の 30% まで
  - 最大 G: ゲーム内の G = 速度 × ピッチ角速度 / 9.8 が難易度の `maxG` を超えないようピッチ入力を頭打ちにする（初期機のプレイヤーは巡航で約 33G 引ける）
- 巡航（patrol）: 経路点を順に回る（水平距離 500m 以内で次へ）。スロットル 0.7
- 発見 → 追尾: 4500m 以内かつ機首から ±70°、または 1200m 以内（向きによらない）。7000m より離れると見失って巡航へ
- 追尾（engage）: 純追尾ではなく予測位置へ。狙い = 相手の「迎撃の予測時間（自分の速さで直進して追いつく時間、最大 3 秒）後の位置」から相手の進行方向の後ろへ 250m（距離 1000m 未満では距離に比例して 0 へ）。3000m より遠いとアフターバーナー（ゲージ 40% 以上）
- 攻撃（attack）: 1400m 以内・機首と機銃の予測照準点のなす角 25° 以内で移り、1.3 倍の距離・1.8 倍の角度を超えたら追尾へ戻る（行き来しない）
  - 予測照準点はプレイヤーと同じ式（弾速 = 機速 + 900、重力の持ち上げ）+ 相手の加速度（前回の判断からの速度の変化）× `leadAccelWeight` × t²/2。これに狙いのずれ（`aimErrorDeg` の円の中で一様、判断ごとに引き直し）を足した向きへ機首を向ける
  - 機銃: 機首とその向きのなす角が `gunConeDeg` 以内・1100m 以内で撃つ。「撃つ `gunBurstSeconds` → 休む `gunPauseSeconds`」をくり返してオーバーヒートさせない。450m より近いとスロットル 0.35 で追い越さない
  - ミサイル: 敵機もプレイヤーと同じロック（±12°・2500m・1.2 秒）。ロック完了中、判断ごとに `missileChance` の確率で撃ち、撃ったら `missileIntervalSeconds` は撃たない。搭載 `missileAmmo` 発（再出現で満タン）。ミサイル本体の性能はプレイヤーと同じ
- 回避（evade）: 自分を追うプレイヤーのミサイルに気づいたら（判断ごとに `evadeMissileChance`）、または被弾が続いたら（受けたダメージを半減期 1.5 秒で足した値が 20 を超え、判断ごとに `evadeHitChance`）。40% でバレルロール（ロール全開 + 最大の 60% で引く）、60% で急旋回（脅威への向きと真上に直交する向きのうち機首に近い側へ最大 G）。どちらもアフターバーナー。ミサイルに追われている間は判断ごとに `flareChance` でフレア（搭載 `flareCharges` 回、クールダウンはプレイヤーと同じ 2 秒）。3.5 秒続け、ミサイルに追われていれば最大 7 秒まで延ばす。終わったら追尾（見失っていれば巡航）
- 離脱（disengage）: HP が 30% を下回る（1 回の出撃で 1 度だけ）、または追尾・攻撃を続けて 25 秒、相手の後方（尾部から ±50°・1800m 以内）を取れないと判断ごとに 50% で。相手と反対の水平方向へ少し上りながら（上向き成分 0.25）アフターバーナーで 8 秒飛び、追尾（見失っていれば巡航）へ戻る
- 地面の回避: 地表（島の上は地形、海の上は海面）から 150m を切る、または今の降下率のまま 3 秒後に切るなら、どの状態より先に「機首の水平方向 + 上向き 1.5」へ引き起こす（機銃も撃たない）。島の上で hard 4 機が 3 分戦っても衝突しないことをテストで確認。それでも衝突したら撃墜扱い（撃墜数には数えない）

| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| easy | 0.8 秒 | 1.4° | 0 | 5° | 0.6 / 1.6 秒 | 0.08 / 25 秒 / 1 | 14 | 35% / 30% | 25% / 2 |
| normal | 0.3 秒 | 0.5° | 0.8 | 4° | 0.8 / 1.0 秒 | 0.2 / 12 秒 / 2 | 24 | 65% / 50% | 50% / 4 |
| hard | 0.15 秒 | 0.35° | 1 | 3° | 1.0 / 0.6 秒 | 0.45 / 7 秒 / 4 | 30 | 95% / 80% | 80% / 6 |

- 敵機 `XF-7 Hornet`: 初期機より少し遅く曲がりにくい（巡航 240・最高 385・ピッチ 70°/秒・ロール 180°/秒・ヨー 20°/秒、アフターバーナー 5 秒）。HP 120（初期機の機銃 12 発、ミサイルは信管が近くで働けば 1 発）、当たり判定の半径 6m
- 敵の機銃: 初期機と同じ弾道で、ばらつき 0.5°・1 発 5・1 機 64 発まで
- 陣営: ミサイルとフレアは全機で共有（プール: ミサイル 16 発、フレアは 1 機あたり 12 個 × 機数）。信管は撃った陣営の機体に反応せず、範囲ダメージも撃った陣営には入らない。撃墜数はプレイヤーが敵側（的・ドローン・敵機）を落としたときだけ数える。敵機は自分たちのフレアには釣られない
- フリーフライトの敵: normal 2 機（上限 4 機）。島の北西 (−1500, 1000, −800)・東 (1600, 1100, 300) から出て、島の周りの四角い経路（高度 900〜1200m）を回る。撃墜（地面への衝突も）から 12 秒後に、出現候補 4 地点のうちプレイヤーから最も遠い地点へ HP・弾満タンで再出現
- 設定: ポーズメニューの設定に「敵 ON/OFF」と「難易度（やさしい / ふつう / むずかしい）」。変えるとすぐ敵を出し直し、localStorage（`skyraid.enemies` / `skyraid.difficulty`）に保存
- 描画: 敵機は 1-1 のプレースホルダー機体と同じ形を赤（`#c8322a`、機首・垂直尾翼はその 45%）で InstancedMesh 1 つ、被弾で 0.08 秒白く光る。敵の曳光弾は赤（`#ff4a3a`）で InstancedMesh 1 つ。増える draw call は 2。撃墜は 2-1 の破片
- 性能: 敵 4 機 + 各ミサイルで、固定ステップ 1 回の戦闘全体（AI・飛行・弾・ミサイル）が平均 0.03ms（AI と敵の飛行・武装だけなら平均 0.021ms・99% 点 0.073ms、Node 上の計測）。テストで 1ms 以内を確認

#### プレイヤーの被弾と警告の決めた数値（2-3。値は `src/data/aircraft.ts` の `hull` / `AIRCRAFT_COMBAT`、HUD は `src/data/hud.ts`）

- 初期機の HP 200、当たり判定の半径 6m（敵の機銃 40 発、敵のミサイルの直撃 約 125〜150 で 2 発）

- HUD: 左のゲージ列の先頭に「HP」ゲージ（30% 未満で赤く点滅）。敵のミサイルに追われている間はラダーの窓の上端より上（6px 空ける）に「MISSILE」を 0.4 秒周期で点滅（下端だと自機の絵と重なるため 4-1 の事前修正で移動）。レーダーに敵機（赤い点）と自機を追う敵のミサイル（点滅する赤い ×）。点の DOM は 12 個を使い回す

## 6. ミッション（キャンペーン）

- 定義はデータ駆動（型は `src/missions/types.ts`、データは `src/data/missions.ts`（M1・M2 と一覧）と `src/data/missions-special.ts`（M3〜M5）。ロジックを含めない）。ミッションを増やすときはデータを足すだけ
- 各ミッション: id・マップ id・開始位置と向き・制限時間（任意）・評価の基準時間・出現物・目標・成功条件・失敗条件・報酬。タイトルとブリーフィング文（3〜4 行）は言語ごとに `src/data/i18n/ja.json` / `en.json` の `missions[id]`（2-5）
- 初期ミッション（5本。2-5。詳細は下の「初期ミッション 5 本」）:
  1. 訓練: リングを 10 個通過し、その後に敵機 2 機（easy）を撃墜。報酬 1000
  2. 初陣: 敵機 3 機（normal）を撃墜。1 機ずつ 20 秒差（2-6 の事前修正。それまでは 2 機 → 40 秒後に 1 機）。報酬 1500
  3. 護衛: 輸送機 1 機を島の東岸の沖から西岸まで。敵機 4 機（normal）が 2 波。輸送機の HP 0 で失敗。報酬 2000
  4. 爆撃: 地上目標 4 つ（レーダー・燃料タンク・格納庫・対空砲。2-6）を破壊。報酬 2000
  5. 遭遇: 敵機 2 機（easy）と戦っていると怪獣（仮実装）が海から出現。HP を 20% 削ると撤退して成功（レイドの導入）。報酬 3000

#### ミッションの仕組み（2-4。ロジックは `src/missions/`、Three.js 非依存）

- ランナー（`missions/runner.ts`）: 固定ステップで、出現物の投入 → 戦域の境界 → 目標の進み具合 → 達成した目標の次を始める → 失敗 / 成功の判定、の順に進める。世界（自機・撃墜数）は `MissionWorld`（`missions/world.ts`。実体は `FlightSession`）を毎ステップ読むだけ
- 進み具合・結果はイベントバスで知らせる（HUD・リザルトが購読）: `objective:activate` / `objective:progress` / `objective:complete` / `boundary:change` / `mission:end` / `mission:abort` / `mission:reward`
- 出現物: 敵機（グループ名・数・難易度・出現位置・巡航経路・狙う相手（プレイヤー / 輸送機優先。2-5）。撃墜されても再出現しない。同時に 4 機まで）/ 的（`data/targets.ts` の出現地点の先頭から数）/ ドローン（軌道の先頭から数）/ 地上目標（グループ・種類・地表の位置・対空砲の難易度。2-5、種類は 2-6）/ 輸送機（グループ・始点・終点。2-5）/ 怪獣（出現位置・歩いて向かう先・撤退する割合。仮実装。2-5）。出現のタイミングは「開始時」「開始から N 秒」「目標 X が始まったとき」「目標 X を達成したとき」
- ミッション中はフリーフライトの的・ドローン・敵機を出さない（定義の出現物だけ）。フリーフライトに戻ると元どおり
- 目標（`missions/objectives/` に 1 種類 1 ファイル）:
  - 撃墜数: 種類（敵機 / 的 / ドローン / 地上目標 / すべて）とグループを指定し、目標が始まってからの撃墜を数える。敵機の地面への衝突も 1 機に数える（再出現しないので、数えないと達成できなくなる）
  - 生存時間: 目標が始まってから N 秒（撃墜されている間は数えない）
  - リング通過: 次のリングだけを順に数える（先のリングを通っても数えない）。判定は「前ステップの位置 → 今の位置」の線分が輪の面を横切り、交点が輪の中心から通過半径以内。向きはどちらから抜けてもよい
  - 護衛（2-5）: グループの輸送機が目的地（水平の円）に入れば達成。進み具合は経路の %（着くまでは 99 で止める）。輸送機を失ったときの失敗は失敗条件「護衛対象の喪失」
  - 破壊（2-5）: グループの地上目標を N 個壊す（出現物の数と同じにすれば全部）。目標が始まる前の破壊は数えない
  - 怪獣（2-5）: 怪獣の全体の HP を指定の割合だけ削れば達成。進み具合は削った %（届くまでは割合 − 1 で止める）。部位 HP はフェーズ6
  - 必須 / 任意。順序は `start`: `withPrevious`（直前と同時）/ `afterPrevious`（それまでの必須目標をすべて達成してから）。任意の目標は次を待たせない
- 成功: 必須の目標をすべて達成。失敗（定義で選ぶ）: 自機撃墜（墜落も）/ 護衛対象の喪失（出ている輸送機のどれかが撃墜された。2-5）/ 制限時間超過 / 戦域離脱。同じステップなら失敗を先に見る
- 終わると画面中央に「MISSION COMPLETE」/「MISSION FAILED」（失敗の理由）を 2 秒出し、そのあとリザルト。その 2 秒もゲームは進む
- 一時停止: ポーズ中はランナーも止まる。中断: ポーズメニューの「ミッションを中断」でミッション一覧へ（報酬・リザルトなし）
- 報酬: 獲得クレジットを `mission:reward` で知らせるだけ（保存・残高はフェーズ3）

#### 評価と報酬（2-4。式と値は `src/data/ranking.ts`）

- 点数 = 100 − 時間の減点 − 被弾の減点
  - 時間の減点 = 50 × clamp((クリア時間 ÷ 基準時間 − 1) ÷ (2 − 1), 0, 1)（基準時間以内で 0、2 倍で最大 50）
  - 被弾の減点 = 50 × clamp(受けたダメージ ÷ 最大 HP, 0, 1)（墜落は含めない。HP 200 の初期機で 40 受けると −10）
- S: 90 点以上 / A: 75 以上 / B: 55 以上 / C: それ未満。失敗・中断はランクなし・報酬 0
- 報酬 = 基本額 × ランク倍率（既定 S ×2 / A ×1.5 / B ×1.2 / C ×1。ミッションごとに上書きできる）

## 8. 怪獣レイド

- 怪獣はオリジナルデザイン（実在IPは使わない）。初代は「海から上陸する二足歩行の巨獣」
- 高さ 150m 想定。市街地マップで建物を壊しながら進む
- 攻撃: 薙ぎ払い（周囲）、咆哮（スタン）、熱線（直線、予兆あり）、投擲（対空）
- フェーズ制: HP 70% / 40% で行動が変化。最終フェーズは制限時間
- 協力要素: 部位を同時に攻撃すると「ブレイク」で大ダメージ。誰かがタゲを取っている間に背面を狙う
- 報酬: 全員に配布、貢献度で差をつけない（協力を優先）

## 9. マルチプレイ

- 方式: PeerJS による P2P。部屋コード（6文字）で接続
- ホストが正。クライアントは入力を送信し、状態を受信して補間表示
- 送信頻度: 入力 30Hz、状態 15Hz。位置・姿勢・速度・HP・弾
- 当たり判定はホスト側で決定。クライアント側は演出のみ
- ホスト切断時はセッション終了（再接続は将来課題）
- 遅延対策: デッドレコニング（速度で外挿）+ スナップ補正

## 10. ビジュアル

- 目標: 写真のような写実。物理ベースの空（大気散乱。HDR 画像は使わない）、PBR マテリアル、水面（ゲルストナー波）、ブルーム、空気遠近、雲（「中」以上は疑似体積、「低」はビルボード）
- 品質設定: 低 / 中 / 高（自動判定 + 手動）
  - 自動判定: 手動設定 > 自動ダウングレードの保存値（`skyraid.qualityAuto`）> GPU 名がソフトウェアレンダラー（SwiftShader・llvmpipe など）なら「低」、それ以外（タッチ端末を含む）は「中」
  - 自動ダウングレード: 飛行開始から 5 秒間（ポーズ中は数えない）の平均 fps が 30 未満なら一段下げて `skyraid.qualityAuto` に保存し、HUD の上端に 2 秒間「画質を下げました」と出す。飛行開始のたびに測る。手動設定（`skyraid.quality`）があるときは行わない。値は `QUALITY_CONFIG.autoDowngrade`
- マップ: 初期は「海岸と島」1枚。後に「市街地（レイド用）」「峡谷（レース用）」
- プレースホルダー期間はプリミティブで進め、フェーズ4で差し替え

#### 島・海・空の決めた数値（1-3。値は `src/data/terrain.ts`、画質は `src/data/quality.ts`）

- 島: 8km 四方（原点中心）を 4×4 チャンク（一辺 2km）に分けて描く。外側は海面だけ。シード `20261029` の simplex ノイズで決まり、毎回同じ形
- 形: 中心からの距離を海岸線の半径（平均 2900m、ノイズで ±18%）で割った t（中心 0・海岸 1）で決める。山 `500 × exp(−4t²)` + 平地 `80 × (1 − t)`（海岸でちょうど 0）+ 丘（fBm、振幅 70m）+ 尾根（リッジノイズ、振幅 90m、山の上ほど強い）。最高点は約 600m（実測 609m。4-6 の浸食後は約 597m）。海岸の手前（t 0.7〜1）で丘を消して砂浜をなだらかにする。海岸の外は t 1〜1.35 で海底へ下がり、深さ 60m で平ら
- 色（頂点カラー。4-6 からは画質「低」だけが使う。「中」以上は下の「地形の決めた数値（4-6）」の層）: 海底 → 砂（海面〜4m）→ 草地 → 森（4-6 から木の配置と同じ密度 × 森の層。従来は 90m 付近）→ 岩（400m 付近。従来は 260m）→ 雪（515m 付近。従来は 470m）。境目は ±25m で混ぜる。法線の y が 0.75（約 41°）より急な斜面は岩、雪は急斜面に積もらない。頂点ごとに明るさを ±6% ばらつかせる
- LOD: チャンクの分割数 128 / 64 / 32 / 16（約 16 / 31 / 63 / 125m 間隔）。カメラからチャンクの箱（高さの範囲込み）までの距離が 描画距離 × 0.12 / 0.3 / 0.6 未満でそれぞれの段、描画距離までは最も粗い段、その先は描かない。粗くするときだけ 100m 余分に待つ（境目でのちらつき防止）。画質「低」は 64 分割から（最も細かい段を使わない）
- LOD の違う隣とのひび割れは、細かい側の縁の頂点を粗い側の直線上に寄せて塞ぐ
- 衝突判定は描画メッシュではなく高さ関数そのもの（`getGroundHeight`）。メッシュは格子の間を直線でつなぐので、低画質では見た目と数 m ずれうる
- 海面は 4-2 で作り直した（下の「海・雲の決めた数値」）。衝突判定は従来どおり「海面 = 高度 0」
- 空・太陽・霧は 4-1 で大気散乱に置き換えた（下の「空・光・ポストエフェクトの決めた数値」）
- 起動位置: (0, 500, 4500)。島の沖合（海岸から約 1.9km）、高度 500m で −Z（島の方向）へ巡航速度。画質「低」の霧（4-1 から 2700m で消える。従来は 2100m）でも海岸が見える距離。そのまま水平に飛ぶと約 16 秒で山の中腹（高度 500m）に当たる

#### 空・光・ポストエフェクトの決めた数値（4-1。値は `src/data/sky.ts`、画質は `src/data/quality.ts`、地形のディテールは `src/data/terrain.ts` の `TERRAIN_DETAIL_CONFIG`）

- 計算は CPU（`src/render/atmosphere-model.ts`、テスト・ライト・露出用）と GPU（`src/render/atmosphere-glsl.ts`）で同じ式。色はすべてリニアの HDR で、最後に ACES でトーンマッピングする
- 太陽: 方位 40°・仰角 32°（午後）。`SKY_CONFIG.sun` を変えるか `Atmosphere.setSun` を呼ぶと、空・ライト・海・露出が計算し直される（7-5 の昼夜用）。大気の外の太陽は 5900K・放射照度 3（平行光源の intensity と同じ単位）。ホワイトバランス 5300K（直射日光が白に近い暖色、地平線の霞が白に写る）
- 大気（Preetham / Hoffman-Preetham 系の単一散乱 + 多重散乱の近似）: Rayleigh 散乱係数 (5.80, 13.56, 33.1)×10⁻⁶/m・スケールハイト 8000m、Mie 1.6×10⁻⁵/m（晴れた日の約 4 倍のうすい霞）・散乱/消散 0.9・スケールハイト 1200m・前方散乱 g 0.76、多重散乱 0.5（等方。空全体から来る光なので太陽の透過率を掛けない）。空気の厚さは Kasten-Young 型の近似（天頂 1・地平線 約 36）
  - 空の明るさ L = E × T_sun × (β_R·P_R + β_M·P_M) / β_ext × (1 − e^−τ) + 多重散乱。T_sun は太陽からの透過率（太陽が低いほど赤い）、τ は視線方向の光学的厚さ。結果として天頂は濃い青、地平線は白く明るく霞み、太陽のまわりは Mie で白く光る
  - 太陽の円盤: 視半径 0.6°（実物の約 2 倍）、明るさは太陽の放射照度 × 40（トーンマッピング後に必ず白く飛ぶ）。画質「中」「低」は太陽のまわりのまぶしさをスカイシェーダーで足す（強さ 0.6・鋭さ 900 と、広いにじみ 0.05・40）。「高」はブルームに任せる
- 空気遠近（霧）: Three.js の霧のシェーダーチャンクを置き換え、全マテリアルに散乱ベースの霧を掛ける（頂点ごとに計算、トーンマッピングの前）。透過率 = exp(−(β_R·ρ_R + β_M,ext·ρ_M) × 距離 × 3)（ρ はカメラと点の高さの間の平均密度。高いところほど薄い）、色 = 同じ向きのスカイの色 × (1 − 透過率)。遠くほど空と同じ色になって溶ける。実際の大気のままだと描画距離（3〜8km）では薄すぎるので、距離を 3 倍にして計算する。4-2b: この倍率はカメラの高さで exp(−高さ / 1960m) 倍に減らす（1000m で地上の 60%、2000m で 36%。地表付近の見え方は 3 倍のまま、上空では霞が薄くなり見下ろした地形・海のコントラストが残る。`SKY_CONFIG.aerial.heightFalloff`）。描画距離の果ては描画距離 × 0.55〜0.9 で背景の色に溶かしきる（地形・海の切れ目を隠す。`QUALITY_CONFIG.fogNearRatio` / `fogFarRatio`）。背景は地平線より上は空、下は「描画距離の外の海面（濃紺の水 + 空の反射）を空気遠近ごしに見た色」（4-2b。スカイドームの地平線より下も同じ色。以前は地平線の霞の色だったため、上空から見下ろすと描画距離の果てが白く溶けて画面全体が白くなった）
- 霧の uniform の読み替え: `fogColor` = 太陽の向き × 放射照度、`fogNear` / `fogFar` = 描画距離の果てのフェード。画質「低」（画面に直接描く）では Three.js が `fogColor` を sRGB に変換して渡すので、逆変換した値を入れておく
- ライト: 平行光源 = 地上に届く太陽光（大気の外の光 × 透過率。午後 32° でリニア約 (2.27, 2.36, 2.01)）。半球ライト = 空全体から水平面に届く放射照度（スカイを 12×24 で数値積分）と、地面の照り返し（反射率 0.1）
- 露出: 地面（反射率 0.15 の拡散面）と空の明るさの対数平均（地面の重み 0.6）が 0.15 になる倍率。ただし露出後の地面が 0.14 より暗くならないよう下限をかける（空が明るくても地形がつぶれない）。午後 32° で約 2.2。トーンマッピングは ACES（全画質）
- 影（画質「中」以上）: 太陽光のシャドウマップ。範囲は機体を中心に 600m 四方（タイトル画面はカメラのまわり）、解像度は「中」1024・「高」2048、光の向きに垂直な面で画素単位に丸めて追従させる（ちらつき防止）。影を落とすのは自機・敵機・ドローン・風船、受けるのは地形と自機。地形自身は影を落とさない（範囲が狭く、山の影が範囲の端で切れるため）。海はシャドウマップの影を受けない（4-2 の雲の影だけ）
- ポストエフェクト（画質「中」以上、three/examples/jsm の EffectComposer）: シーン（HalfFloat・MSAA 4x）→ ブルーム（「高」のみ。UnrealBloomPass、強さ 0.35・半径 0.4・しきい値は露出後の輝度 2.2）→ 仕上げ 1 パス（ビネット 四隅で 22% 暗く + 露出 + ACES + sRGB）。「低」はポストエフェクトなしで、ACES はレンダラー側（各マテリアルの最後）
- 地形のマテリアル: 「中」以上は PBR（`MeshStandardMaterial`、粗さ 0.95）+ 三面マッピングの手続きノイズ（テクスチャ画像なし）で頂点カラーの明るさをばらつかせる。細かい粒（一辺 1.5m・±25%・120〜380m で消える）、まだら（8m・±20%・500〜1400m）、大きな色むら（60m・真上から投影・草地は黄緑 ⇄ 深緑）。急斜面（法線の y 0.85→0.65）は岩として粒を 1.6 倍。「低」は従来どおり Lambert（頂点カラーだけ）
- マテリアル: 機体・的・ドローン・ミサイル・煙・破片は `MeshStandardMaterial`。発光する演出（曳光弾・火花・マズルフラッシュ・フレア・爆発の閃光）は基本色が黒の `MeshStandardMaterial` + emissive で、明るさは露出後の値で指定（曳光弾 1.1・火花 1.3 は色が分かるようブルームのしきい値の下、マズルフラッシュ 5・フレア 6・爆発 5 はブルームで光る）。霧は掛けない
- 品質フラグ（`QualityPreset`）: 低 = 影なし・ポストエフェクトなし・ブルームなし・地形ディテールなし / 中 = 影（1024）・ポストエフェクト・地形ディテール、ブルームなし / 高 = すべて（影 2048）
- デバッグ表示（F3）に「steps」（1 フレームの描画ステップ数: シャドウマップ + シーン + ポストエフェクトのパス。ブルームは内部 13 回）を足した。draw calls はポストエフェクトのパスを含めた 1 フレームの合計

#### 海・雲の決めた数値（4-2。海は `src/data/ocean.ts`、雲は `src/data/clouds.ts`、風は `src/data/wind.ts`、画質は `src/data/quality.ts`）

- 風: 向き 30°（+X から +Z へ。島の南西から北東）。海の波・さざ波・泡の流れ・雲の流れ（9 m/s）はすべてこの向きを基準にする。`WIND_CONFIG.direction` を 1 つ変えると全部が揃って回る
- 海面（画質「中」以上）
  - 波: ゲルストナー波 6 本。うねり 2 本（風向き −20° / +35°、波長 220 / 140m、振幅 0.5 / 0.35m、鋭さ 0.1）+ 風波 4 本（0° / +25° / −30° / +50°、波長 42 / 27 / 17 / 11m、振幅 0.22 / 0.15 / 0.1 / 0.06m、鋭さ 0.22 / 0.18 / 0.16 / 0.14）。振幅の合計 1.38m（上限 1.5m。船酔い防止）、鋭さの合計 0.9（< 1 で波の頂点が輪にならない）。速さは深海の分散関係 ω = √(g·k)（うねり 18.5 m/s・周期 11.9 秒、いちばん短い風波 4.1 m/s・2.7 秒）。計算は `src/render/gerstner.ts`（CPU、テスト用）と頂点シェーダーで同じ式。見た目だけで、衝突判定は「海面 = 高度 0」のまま
  - 浅瀬では波を小さくする（水深 0.3m で 0、8m で元の振幅）。波打ち際で海面が砂浜にかぶらない
  - メッシュ: カメラ中心の同心リング（角度 160 分割、半径 2m から描画距離 × 1.1 まで等比。隣の輪との間隔 ≒ 円周方向の間隔で、距離 d での頂点の間隔は約 d × 0.039）。「中」約 3.3 万頂点（三角形 約 6.6 万）、「高」約 3.5 万頂点（約 7 万）。4-1 の平面（64 分割、約 0.4 万頂点）から増えた分は頂点シェーダーだけで、画質「中」のスマホでも負担は小さい見込み。頂点の間隔が波長の 1/8 を超えた波から消し始め、1/4 で消しきる（遠くのちらつき防止）
  - さざ波: 頂点は動かさず、フラグメントで 2D 勾配ノイズ（値と微分を同時に出す。テクスチャ画像なし）から法線を作る。層 1（模様 9m・風向きに 1.2 m/s・傾き 0.32・250〜1600m で消える）、層 2（2.6m・+70° に 0.6 m/s・0.22・80〜450m）、層 3（0.8m・−45° に 0.3 m/s・0.14・30〜140m）。「中」は 2 層、「高」は 3 層（`QualityPreset.oceanLayers`）
  - 色: 水の色（反射率）は水深で混ぜる（浅瀬のターコイズ #2fb8b0 → 沖の濃紺 #0a2c4a、exp(−水深 / 6m)）。照らす光は地形と同じ太陽 + 空の放射照度 / π。空の反射は Schlick のフレネル（F0 0.02）× 0.9 で、空の色はスカイと同じ大気散乱の式（4-1）
  - 太陽の照り返し: GGX（Schlick のフレネル、Kelemen の可視項）。粗さ α は近く 0.07、さざ波が弱まった・消えた遠くでは 0.2（細かい波を粗さとして扱い、照り返しが沖まで帯状に広がる）
  - 4-2b: さざ波の傾きを距離で 1 / (1 + (距離 / 500m)^1.6) 倍に弱める（500m で 50%、2000m で約 10%）。粗さ α もこの割合で近く → 遠くの値へ移す。1 画素が海面で覆う幅（画面の微分）が模様の大きさ × 0.15 を超えた層は消し始め、× 0.4 で消しきる（画素より細かい法線を使わない）。照り返しの強さは 1 → 0.6。波のない海面（ゲルストナー波の法線）で太陽を映す向きから 7° 以内を帯とし、20° まで弱め、帯の外は 0.12 倍・露出前の輝度 0.35 で頭打ち（露出の上限 3 でもブルームのしきい値 2.2 未満。「低」の簡易版も同じ帯を使う）
  - 水面下の散乱っぽい明るさ: 太陽の方を見たとき、波の山ほど緑がかったターコイズ（#2aa58f、強さ 0.6）が透けて明るくなる
  - 海岸の泡: 地形の高さ関数から起動時に水深の格子（8km 四方を 384×384、約 21m 間隔。HalfFloat のテクスチャ、線形補間。約 60ms）を作り、「水深 ÷ 水深の勾配」で海岸線までの距離を見積もる。距離 26m 以内（水深 3m 以内）に白い帯（反射率 0.8）。帯の端は 7 秒周期で ±35% 寄せては返し、ノイズ（3.5m）でちぎって風下へ流す。遠浅でも急でも帯の幅が揃う
  - 「高」: 画面空間の反射は入れず、空の反射を 1.08 倍・太陽の照り返しを 1.3 倍に（`QualityPreset.oceanBoost`）。雲の影も受ける
- 海面（画質「低」）: 4-1 の簡易版（カメラ追従の平面、64 分割、頂点の波はうねり 1 本を正弦波で、水の色と空の色は頂点で計算）に、さざ波の層 1 だけをフラグメントで足してフレネルと照り返しを揺らす。頂点数は変えない。水の色は「中」以上の沖と同じ濃紺
- 雲（画質「中」以上）: 高度 1500〜2200m の層。カメラに追従する板（層の下面と上面の 2 枚、1 メッシュ）を描き、画素ごとに視線と層の交わる区間を一定の歩数で進む疑似体積（「中」8 歩・「高」12 歩。上限はシェーダーの定数 12、`QualityPreset.cloudSteps`）。1 本の視線で進むのは最大 1500m。カメラが層の下なら下面だけ、上なら上面だけ、中なら両方を描く
  - 密度: 起動時に作るタイル状の 3D ノイズ（32³、Worley と値ノイズの fBm を 6:4。約 70ms）を 3D テクスチャにして、形（4200m で 1 周）・縁を削る細部（640m）・被覆率を場所ごとに ±0.15 揺らす大きな模様（23km）の 3 回読む。高さの重みは底で平ら（下から 10% で最大）・上は丸く細る（積雲）。形 × 重みの上位「被覆率」だけを雲にする（被覆率 0.45。上げるほど密度が増える）。消散係数 0.03/m
  - 光: 太陽の方へ 140m 先の密度を 1 回取って自分の影にし、さらに下ほど暗く（底は 45%）。位相関数は Henyey-Greenstein の前方（g 0.6）と後方（−0.15）を 6:4 で混ぜる（太陽の方を見ると縁が光る）。空の光は上ほど明るい（底 0.45）。結果、下から見ると底が灰色で縁が明るく、上から見ると白い綿
  - 歩く位置は各歩の中央（画素ごとにずらさない）。層の外から入る視線は全画素が同じ高さの組で取るので縞にならず、ずらすと 8 歩では砂のようなざらつきになったため
  - 遠くの雲は地形・海と同じ空気遠近の式で空の色に溶け、描画距離 × 0.55〜0.9 で消える
  - 4-2b: 板はカメラの位置に付いて動くが向きは常に世界の水平。視線は画素の NDC からカメラの投影の逆行列とワールド行列で世界座標の向きを求める（ロール・背面飛行でも雲が地平線と同じだけ傾く）
  - 風で 9 m/s で流れる（ポーズ中は止まる）
- 雲（画質「低」）: ビルボード 40 枚（InstancedMesh、draw call 1）。カメラのまわり 2600m 四方に置いて回り込ませ（端の 30% で薄くする）、世界の上方向を軸にカメラへ向ける（右は常に水平でカメラのロールに追従しない。上下はカメラの方へ傾けて、層の上・真下から見ても線にならない。4-2b）。形はノイズの輪郭（平らな底）、色は空の光（太陽 + 空。上ほど明るく底は暗い）。幅 450〜1100m、高さは幅 × 0.45、高度 1600〜1950m
- 雲の中の霧: カメラが層の中にいると、画面全体に薄い白（層の中にいるだけで 22%、カメラの位置の雲の密度で最大 60%。層の端 60m でぼかし、濃さは 1/4 秒で追従）を重ねる。カメラの位置の密度は GPU と同じ式・同じノイズを CPU で読む。疑似体積は層の中では水平に近い視線ほど薄くする（板に当たらない向きとの境目を隠す）
- 雲の影（画質「高」のみ。`QualityPreset.cloudShadows`）: シャドウマップではなく、地形・海の点から太陽の方へ層の 30% の高さまで伸ばした点の密度（細部なし）で直射光を最大 55% 暗くする。地形は直射光だけ、海は照り返しと水の中の光の太陽の分だけ暗くなる
- draw call: 海 1 + 雲 1（疑似体積かビルボード）+ 雲の中の霧 1（層の中にいるときだけ）= 最大 3（4-1 から +2。海は従来も 1）
- 品質フラグ（4-2 で追加）: 雲の方式 `cloudMode`（低 billboard / 中・高 volume）、雲の歩数 `cloudSteps`（— / 8 / 12）、海の層数 `oceanLayers`（1 / 2 / 3）、反射の強化 `oceanBoost`（高のみ）、雲の影 `cloudShadows`（高のみ）

#### 地形の決めた数値（4-6。地形は `src/data/terrain.ts` の `TERRAIN_CONFIG.shape.coast` / `TERRAIN_CONFIG.erosion` / `TERRAIN_DETAIL_CONFIG`、木は `src/data/vegetation.ts`、画質は `src/data/quality.ts`）

- 方向性: 写真のような写実。テクスチャ画像・Web フォントは使わず、すべて手続き生成
- 浸食（`src/render/terrain-gen/erosion.ts`、Three.js 非依存）: 起動時に 1 回、粒子ベースの水力浸食。島を覆う 7400m 四方を 256×256（約 29m 間隔）の格子にし、雨粒 28000 粒（シード固定）を陸の格子点に落とす。雨粒は最急勾配へ慣性 0.05 で 1 マスずつ最大 30 歩進み、運べる量（下り坂の勾配 × 速さ × 水量 × 8、最低 0.01）に余裕があれば 40% 削り（3×3 の筆で周りに配る）、超えたら 30% 落とす。水は 1 歩で 2% 蒸発。海に着いた雨粒は運んでいた土ごと消える。結果、尾根が鋭くなり、谷に溝ができ、山裾に扇状の堆積が出る
  - 浸食の前後の差分を Catmull-Rom で補間して高さ関数に足す（細部は従来のノイズのまま）。`getHeight` がその値を返すので、衝突・リング配置・AI の地形回避・描画メッシュ・水深の格子はすべて同じ高さを使う
  - 浸食前の高さが海抜 5m 以上の所にだけ効かせ（5〜20m で 0 → 1）、削っても 5m より下にはしない。海岸線・浅瀬・水深の格子（4-2c）は浸食の前と同じ
  - 最高点は 609 → 約 597m（浸食で変わった高さの平均 約 22m・最大 約 140m）。起動時間は Node で約 110〜175ms（上限 200ms をテストで確かめる。Web Worker は使わない）
- 海岸の作り分け: 中心から見た向きと風向き（`WIND_CONFIG.direction` 30°）の内積をノイズ（±0.3）で揺らし、−0.15〜0.55 で風上 / 風下らしさ 0 → 1
  - 外洋側（風上。南西）: 内陸から緩く上がった台地（海岸から約 200m で 32m）が、海岸の約 35m の幅で崖になって海へ落ちる。崖の下の海底の棚は 45% まで狭い（すぐ深い）。崖は浸食の後で足す（格子より細いので浸食で崩さない）
  - 風下（北東）: 海岸の手前（t 0.8〜1）を最大 55% 低くして遠浅の浜を広げる。浸食の堆積は風下で 1.6 倍、風上で 0.4 倍
  - どちらも t = 1（海岸線）の高さ 0 は変えないので、海岸線の平均半径は浸食・作り分けの前と同じ（テストで ±5% 以内を確かめる）
- 質感の層（画質「中」以上。地形のシェーダーの中で決める。`src/render/terrain-layers-glsl.ts`）: 海底 → 砂浜（上端は風上 2.5m・風下 8m）→ 草地 → 森（木と同じ密度 × 高度 20〜350m × 傾斜 25° 以下。暗い緑のまだら）→ 高原（340m〜。草と岩屑）→ 岩（400m〜、または傾斜 30° 以上）→ 崖（傾斜 50° 以上。高さ 4.5m 間隔の地層の縞をノイズでうねらせる）→ 雪（515m〜。北向き（+Z。太陽の反対側）の斜面ほど最大 80m 低くまで、南向きは 24m 高く。傾斜 45° より急な所には積もらない）
  - 境目: 大小 2 枚のノイズ（37m / 9m）で高さの境目を ±14m、傾斜の境目を ±5° ずらす（直線にならない）
  - 粒: 三面マッピングの値ノイズ 3 枚（細 0.8m・粗 3.5m・まだら 14m。それぞれ 100〜300m / 250〜800m / 700〜2000m で消える）を層ごとの強さで混ぜる。草は細かい粒が強く（±28%）、岩は粗い粒が強い（±35%）。大きな色むら（60m、草地の黄緑 ⇄ 深緑）は 4-1 のまま
  - 法線の細部（`QualityPreset.terrainNormalDetail`。「中」「高」）: 岩・崖の面を、三面マッピングのノイズの勾配（4.5m・深さ ±1.2m と 1.3m・±0.25m）と崖の縞の段差（0.25m）で揺らす。250〜900m で消える
  - 「低」は頂点カラーの Lambert のまま（森は木と同じ密度、岩 400m・雪 515m に揃えた）
- 木（`src/render/vegetation.ts`、配置は `src/render/terrain-gen/forest.ts`）: 森の層（高度 20〜350m・傾斜 25° 以下。傾斜は高さ関数の 6m の前進差分）に、森の密度（値ノイズ 420m と 95m を 0.65 : 0.35 で混ぜ、0.38〜0.62 で 0 → 1）に比例して決定的に撒く。本数は 低 3000 / 中 12000 / 高 30000（`QualityPreset.treeCount`）。少ない本数は多い本数の先頭と同じ並び
  - 近く（600m 以内）: 1 つの InstancedMesh の針葉樹（円錐 2 段 + 円柱、約 40 三角形、葉は下ほど暗い）。高さ 11〜23m、幅は高さの 0.64〜0.9 倍、明るさ ±18%。風（`WIND_CONFIG.direction`）の向きに梢が最大約 0.35m、1.4 rad/s で揺れる。カメラが 50m 動くごとに 650m 以内の木を詰め直す
  - 遠く: 全部の木の十字ビルボード（カメラを向く縦の板 + 樹冠の高さの水平の板）を 1 つのジオメトリで。輪郭はフラグメントで捨てる（縦は縁がぎざぎざの三角形と幹、水平は縁が波打つ円）。色は 4-1 の空気遠近で距離とともに空に溶ける
  - 根元は 1.5m 沈める（地形の LOD の直線補間で浮かないように）。影は落とさず受けず、衝突判定もしない
  - 木の影の代わり（「高」のみ、`QualityPreset.treeShade`）: 地形のシェーダーで、地面の点から太陽の方へ木の高さ × 0.8 ずらした点の森の密度 × まだら（5m）で直射光を最大 50% 暗くする。1500〜2500m で消える
- 品質フラグ（4-6 で追加）: 木の本数 `treeCount`（3000 / 12000 / 30000）、法線の細部 `terrainNormalDetail`（— / あり / あり）、木の影の代わり `treeShade`（高のみ）
- draw call: 木 2（近くの InstancedMesh + 遠くのビルボード。近くに木がないときは 1）。その他は増やさない。地形の三角形数は変えない（「低」は従来どおり 10 万以下）

## 11. UI

- タイトル → モード選択 → （ハンガー）→ ブリーフィング → プレイ → リザルト
- HUD: 速度、高度、HP、武装残弾、ロックオン枠、レーダー、ミッション目標
- 全画面DOM。文字は日本語・英語の2言語（i18n JSON）

#### HUD の決めた数値（1-4。値は `src/data/hud.ts`）

- 色はシアン `rgba(110, 240, 255, 0.85)` の 1 色 + 警告の赤。箱・レーダーの背景は半透明で背景が見える。フォントは Web フォントなし（数字は等幅のシステムフォント、ラベルは system-ui）
- 中央: ピッチラダー。10° ごと ±90°、機首上げ側は実線・機首下げ側は破線、数字は絶対値。1° = 8px（狭い画面は 5px）。楕円の窓（260×280px、狭い画面 180×170px）で切り抜き、ロールと逆に回す（右バンクで反時計回り）。画面中央が機体のピッチ。窓は画面中央に固定（カメラの見え方と厳密には一致しない、非コンフォーマル）
- 進行方向マーカー: 機首方向 1000m 先の点をカメラで投影した位置（横滑りなしなので進行方向 = 機首方向）。追従カメラの遅れ・旋回の先読みで画面中央から動く
- 左（ラダーの左隣）: 速度（m/s 相当、整数に丸め）、スロットル位置、アフターバーナーゲージ（点火中は濃く、使い切って再点火待ちは薄く）
- 右（ラダーの右隣）: 高度（海面基準、m、整数に丸め）。地表（島の上は地形、海の上は海面）との距離が 100m 未満で高度の箱を赤く点滅させ、下に「PULL UP」を点滅表示
- 失速（`FlightState.stall` > 0）で「STALL」をラダーの窓の上端に赤く点滅表示。点滅は 0.8 秒周期
- 下: 円形レーダー（機首方向が上）。半径 8000m（起動位置の沖合 4.5km から島が収まる）。直径 120px（狭い画面 88px）。自機は中央の三角、島の中心は四角、範囲外は縁に中抜きで表示。敵機は赤い点、自機を追う敵のミサイルは点滅する赤い ×（2-3）
- 狭い画面: 幅 760px 以下または高さ 480px 以下（スマホ横画面）で、ラダー・文字・レーダーを縮小
- 配置: 速度・高度の箱はラダーの両脇（画面端はタッチのヨーボタン・スティック・ボタン群が使う）。タッチ操作中はレーダーを「スティックの待機位置の右端」と「右下のボタン群の左端」の間の中央に寄せる（画面中央から左へ 44px）
- 更新: 数値テキストは表示文字列が変わったときだけ、ラダーは角度が 0.1° 以上、マーカーは 0.5px 以上、ゲージは 0.005 以上変わったときだけ書き換える。HUD を隠している間は計算もしない
- 表示切替: H キー、またはポーズメニューの設定の「HUD ON/OFF」。初期は表示、保存はしない

#### タイトル・モード選択・ポーズの決めた数値（1-6。値は `src/data/screens.ts`）

- 画面の状態: 読み込み中（boot）→ タイトル → モード選択 →（キャンペーン: ミッション一覧 → ブリーフィング →）飛行 ⇄ ポーズ →（ミッションの終わり: リザルト）。モード選択からタイトルへ戻れる。`?skipTitle` は読み込み中 → 飛行。遷移表は `src/core/game-state.ts`
- 固定ステップ更新（ゲームの時間）は飛行中だけ進める。ポーズ・タイトル・モード選択では止め、止めている間の時間は貯めない（再開しても一気に進まない）。描画は続けるが、ポーズ中は機体・カメラ・海の波も止まる
- 画面遷移は CSS transition のフェード 0.3 秒。カメラが切り替わる遷移（モード選択 → 飛行、ポーズ → タイトル）は一瞬黒にして 0.3 秒で明ける暗転で隠す
- 読み込み中: 起動時に `BOOT_TASKS`（`src/core/boot.ts`）を順に Promise で待ち、進捗バーを出す。アセットはまだ無いので即完了
- タイトル: 背景は実際のシーン。デモカメラが島の中心の周りを半径 3600m・高度 480m で 150 秒に 1 周（約 2.4°/秒）し、島の中心の高さ 800m を見る（2-5 の事前修正。それまでは高度 600m・注視点 200m。山頂（約 600m）を画面の中央より下に置き、山が画面の下半分に入るようにした）。開始位置は起動位置と同じ南側（+Z）。ロゴは「SkyRaid」のテキストと CSS のみ（サブタイトルなし。画像・Web フォントなし）。画面のどこをタップ / Enter で開始
- モード選択: フリーフライトとキャンペーン（2-4）を選べる。PvP・レイドは「近日」と表示して押せない。Esc / 「← タイトルへ」で戻る
- フリーフライト: モード選択から入るたびに起動位置・巡航速度から始める。墜落は撃墜と同じ扱い（2-4）。戦域の境界の外では「RETURN TO BATTLEFIELD」を出すだけ（カウント・失敗なし）
- ポーズ: Esc / パッドの Start / 右上の ⏸ ボタン（一辺 44px。タッチ操作中は右上のヨーボタンの左隣、間隔 12px）。メニューは「再開」「設定 ▼」（画質・タッチ・HUD・全画面。開閉できる）「タイトルへ」。Esc / Start でも再開
- 飛行中の画面上部の設定バーは廃止し、ポーズメニューの設定に移した。F3（デバッグ表示）と H（HUD）はメニュー中も効く
- タイトル・モード選択では機体・HUD・タッチ操作を隠す。ポーズ中は HUD を残し、タッチ操作は隠す
